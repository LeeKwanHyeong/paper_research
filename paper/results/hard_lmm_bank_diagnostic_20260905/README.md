**판정 — value 표현·결합 방식의 신규 후보 구현 보류**

Instacart separate-key에서 전체 value bank의 수량 방향 차이는 남아 있습니다. 실제 사용 비중을 반영하면 그 차이가 크게 좁아지고, top-4의 가중 평균 뒤에는 표본별 기여가 더 일정해집니다. 이번 진단은 **차이가 줄어드는 지점**을 확인했습니다. 이를 성능 저하의 원인으로 확정하거나, 특정 value·결합 방식 변경의 개선 근거로 삼기에는 부족합니다.

시간 방향에서도 표본별 기여가 일정해지는 경향이 나타납니다. 수량만 억제되거나 시간 과업이 memory를 독점한다는 주장은 지지하지 않습니다. Taxi는 평균 뒤 수량 방향의 차이가 줄었어도 기존 validation 성능이 개선됐으므로, 다양성 자체를 높이는 것을 목표로 삼지 않습니다.

**현재 기준선과 실행 범위 — 완료 / paper_research, 로컬 CPU**

- 소스 기준선: `master`, `aac1c00`. 원본 Hard-LMM을 공식 기준선으로 유지합니다. 앞선 두 통계 query 후보의 보류 판정도 유지합니다.
- Taxi·Instacart 원본 및 separate-key seed42 checkpoint 네 개와 기존 train cache를 재사용했습니다. Dataset당 동일한 train 표본 8,192개, bank 64개, 실제 top-4를 비교했습니다.
- 기존 두 train 구간은 series가 겹치지 않도록 나뉘어 있습니다. 모든 checkpoint는 이 train 자료로 학습됐으며 validation으로 선택됐으므로, 이번 구간별 확인은 독립적인 일반화 검증이 아닙니다.
- 새 데이터 행, target 수량·시간 label, residual label, validation·held-out 행을 분석에 사용하지 않았습니다. Cache 파일에는 기존 train label도 포함되지만, 로드 직후 계약의 입력 필드만 남겼습니다.
- 모델 변경·파라미터 업데이트·추가 fitting·5090 접속 없이 완료했습니다. 5090 실행은 이번 진단에 필요하지 않았습니다.

**측정 방법 — 전체 bank, 선택 비중, 평균 뒤 기여를 구분**

각 checkpoint의 value를 그 checkpoint의 수량·시간 head 방향으로 투영했습니다. 수량은 softplus 이전 logit 기여, 시간은 legacy 시간 likelihood의 intercept 기여입니다. 서로 다른 checkpoint의 같은 slot 번호에 같은 의미를 부여하지 않았습니다.

- **전체 bank 균등 분포:** 모든 64개 slot을 같은 비중으로 봅니다.
- **선택된 slot의 균등 분포:** 표본에서 한 번이라도 top-4에 등장한 slot을 같은 비중으로 봅니다.
- **실제 선택 비중 분포:** 각 slot이 받은 실제 attention weight의 합을 표본 수로 나눕니다. 아래 표의 “선택 비중 SD”는 이 분포의 표준편차입니다.
- **평균 뒤 기여:** 각 표본에서 실제 weight로 top-4를 합한 값입니다. “표본 간 비율”은 이 값의 분산을 실제 선택 비중 분산으로 나눈 값입니다.

마지막 두 분산은 `전체 선택 분산 = 표본별 평균의 분산 + 표본 내 분산의 평균`으로 정확히 분해했습니다. 이 항등식은 평균화가 차이를 얼마나 줄이는지 설명하며, 그 감소가 유해한지는 알려주지 않습니다. 두 head의 크기 차이를 배제하기 위해 단위 head 방향 분산/전체 벡터 분산도 별도 기록했습니다.

**수량 방향 — 전체 value가 평평해진 현상은 아님**

| Dataset | Checkpoint | 전체 bank SD | 선택 비중 SD | 평균 뒤 SD | 표본 간 비율 |
|---|---|---:|---:|---:|---:|
| Taxi | 원본 | 0.024319 | 0.044091 | 0.042534 | 93.062% |
| Taxi | Separate-key | 0.036061 | 0.044695 | 0.019323 | 18.691% |
| Instacart | 원본 | 0.065422 | 0.014021 | 0.007618 | 29.522% |
| Instacart | Separate-key | 0.113924 | 0.010458 | 0.003228 | 9.526% |

Instacart separate-key의 선택 비중 분산은 전체 bank 분산의 **0.8428%**입니다. 평균 뒤 분산은 선택 비중 분산의 **9.5261%**, 전체 bank 분산의 **0.0803%**입니다. 단, 전체 균등 분포와 경험적인 선택 분포는 서로 다른 분포입니다. 이 비율은 유용한 정보의 손실률이 아닙니다.

실제로 등장한 14개 slot을 균등하게 볼 때 수량 SD는 **0.074561**로, 실제 선택 비중 SD **0.010458**보다 큽니다. 이는 사용 비중이 일부 slot에 집중되는 현상도 포함한다는 뜻입니다. 상위 4개 slot이 전체 attention mass의 **99.5300%**를 차지했습니다. 이전 진단의 **선택 횟수 비중 99.2218%**와는 정의가 다른 값입니다. 사용이 드문 slot의 수량 방향 차이가 크다는 사실만으로 그 slot을 더 선택하는 것이 유익하다고 판단할 수 없습니다.

Instacart의 평균 수량 logit 기여는 **+0.262647**로 남아 있습니다. 표본별 변동이 작다는 것이 memory의 기여가 0이라는 뜻은 아닙니다. 또한 전체 bank의 유효 차원수는 **15.715**, 실제 선택 비중으로 가중한 bank의 유효 차원수는 **1.419**입니다. 후자를 “전체 value bank 붕괴”로 표현하지 않습니다.

**시간 방향 — 수량만의 억제나 clamp 원인으로 해석하지 않음**

| Dataset | Checkpoint | 전체 bank SD | 선택 비중 SD | 평균 뒤 SD | 표본 간 비율 |
|---|---|---:|---:|---:|---:|
| Taxi | 원본 | 0.006197 | 0.007738 | 0.005959 | 59.294% |
| Taxi | Separate-key | 0.008458 | 0.009678 | 0.004568 | 22.282% |
| Instacart | 원본 | 0.126500 | 0.029551 | 0.019204 | 42.232% |
| Instacart | Separate-key | 0.117689 | 0.036264 | 0.009198 | 6.434% |

Instacart separate-key에서 단위 head 방향 분산/선택 벡터 분산은 수량 **0.1368%**, 시간 **1.0906%**입니다. 시간 방향의 상대적인 차이가 더 크지만, 실제 평균 뒤 시간 기여의 표본 간 분산 비율도 **6.4338%**에 그칩니다. 전체 벡터 기준으로 평균 뒤 남는 표본 간 분산 비율은 **2.4947%**입니다. 시간 과업의 독점이나 수량·시간 gradient 충돌을 입증한 결과가 아닙니다.

실제 legacy 시간 loss의 **상한만 있는** intercept clamp를 적용해 memory on/off 기여를 계산했습니다. 네 checkpoint 모두 이번 표본에서 clamp가 작동한 비율은 **0%**였습니다. 따라서 관측된 평탄화는 이번 표본의 clamp 결과가 아닙니다. Target gap을 사용하지 않았으므로 Time NLL이나 시간 예측 오차의 개선 여부는 평가하지 않았습니다.

**Train 내부 일관성과 결합 방식 변경의 한계**

- Instacart separate-key의 두 구간에서 수량 평균 뒤 SD는 **0.003188 / 0.003265**, 표본 간 분산 비율은 **9.5295% / 9.5225%**였습니다. 시간 비율은 **6.6984% / 6.1740%**였습니다. 주요 현상은 두 구간에 공통으로 나타났습니다.
- Separate-key의 표본별 유효 선택 수는 Instacart **3.862**, Taxi **3.888**로 최대 4에 가깝습니다. 동일 top-4에서 실제 가중 평균과 균등 평균의 수량 기여 RMS 차이는 각각 **0.002400 / 0.005117**입니다. 이 비교는 현재 고정 value의 산술 비교이며 새 모델 성능 비교가 아닙니다.
- Taxi의 수량 표본 간 분산 비율은 원본 **93.06% → separate-key 18.69%**로 줄었습니다. 별도로 완료된 [validation 기록](../hard_lmm_key_value_screening_5090_20260904/README.md)에서 Taxi body MAE는 원본 대비 **26.77% 개선**됐습니다. 이번에 validation을 다시 평가하지 않았으며, 두 사실의 공존은 “평균 뒤 차이가 클수록 성능이 좋다”는 기준을 정당화할 수 없음을 보여줍니다.
- Instacart에서 선택과 평균화가 기여의 변동을 제한하는 것은 확인했지만, 어느 수정이 필요한 오차 보정을 만들어 낼지는 확인하지 않았습니다. 이미 보류한 두 통계 query와 별개로, diversity loss·top-k·temperature·비선형 fusion을 자동으로 새 후보로 추가하지 않습니다.
