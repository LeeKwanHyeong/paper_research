# Intermittent 원인 진단 준비

**기존 증적 분석과 진단 계획 구체화 — 완료**

- 대상은 paper_research, 브랜치 `codex/hard-lmm-causal-qkv`, 로컬에 회수된 seed42 validation 증적이다. B epoch77과 dual-timescale 후보 epoch37을 비교한다. 기존 학습과 최종 감사는 현재 기준선이며 다시 실행하지 않는다.
- 이번 작업에서 원본 summary의 수량 5구간·이력 3구간을 비교하고, 양 모델 전체 RMSE·MAE·평균 오차 및 차이 기여 합계를 검증했다. 결과는 [구간별 진단](aggregate_findings.md), [수치·출처·검증](aggregate_diagnosis.json), [CSV](strata_comparison.csv)에 저장했다.
- 새 추론, checkpoint 다운로드·복원, 원격 실행, 학습, 모델 변경은 수행하지 않았다. 아래 행 단위 진단은 준비된 다음 작업이다. Scheduler는 기존 단일 학습의 종료 상태인 PAUSED를 유지한다.

**현재 확인한 차이 — 완료**

- 전체 제곱오차 차이 ΔMSE는 +0.250403이다. 관측 이력 65–128이 순증가의 82.00%, 128 초과가 17.77%를 설명한다. 이력 64 이하는 RMSE가 거의 같지만 MAE는 증가했다.
- 수량 (31,46]과 (46,187]은 각각 순증가의 31.30%, 41.97%를 차지한다. >187 tail은 25.61%다. (2,31]은 RMSE가 소폭 감소하면서 MAE는 증가했다.
- 전체 평균 오차는 +0.073575에서 −0.174722로 바뀌었다. 그러나 전역 bias² 차이는 ΔMSE의 10.03%이며 89.97%는 centered MSE 차이다. 전역 평균 과소예측만으로 악화를 충분히 설명할 수 없다. 조건별 bias 변동도 전역 centered MSE에 포함되므로 이를 순수한 무작위 분산으로 부르지 않는다.
- 이력 128 초과에서는 평균 오차가 +0.087238 → +0.111105로 증가했다. 전 구간의 일괄적인 과소예측이라는 해석은 맞지 않는다.
- 수량과 이력은 같은 validation의 서로 다른 주변 분포다. 위 기여를 더하거나, 수량31–187 × 이력65–128의 교집합이 원인이라고 단정하지 않는다. 순증가 비중은 양의 악화 총량 비중과 다르다.

**동일 표본 예측을 준비하고 재현성을 확인 — 다음 작업 1**

- 대상: 로컬 CPU의 별도 진단 폴더. 고정 모델은 B와 현재 Intermittent 후보 두 개만 사용한다. RMTPP·THP와 다른 데이터셋은 이번 원인 진단의 주 비교에 추가하지 않는다.
- 먼저 B·후보의 checkpoint 파일 및 tensor-state SHA, 원본 source revision, 데이터·split manifest·summary SHA를 검증한다. B의 로컬 checkpoint 경로는 기존 raw-RMSE alignment 산출물에서 발견했지만 파일 hash·복원은 이번 준비에서 실행하지 않았다. 후보는 최종 감사의 원격 checkpoint 경로가 확인되어 있으며 로컬 확보 여부는 미확인이다. 이전 후보나 Instacart checkpoint로 대체하지 않는다.
- 기존 `/tmp/paper_research_dual_timescale`의 ca8823e 소스를 이용하는 로컬 CPU 추론기를 재사용할 수 있는지 확인한다. B의 f752434 학습 경로와 loader·encoder·head의 호환성을 확인한 뒤 사용한다. 임시 소스 존재는 확인했지만 새 진단의 소스 감사는 미실행이다. 원격 서버 사용이 필요하면 현재 서버 지정과 실행 범위를 먼저 확인한다.
- Instacart 추론기의 lookback52 / max_seq_len64, B 캐시, 수량 경계, 비교 모델과 입력 파일은 하드코딩되어 있다. 파일을 그대로 실행하지 말고 Intermittent의 **lookback520 / max_seq_len256**, train 경계 **2·31·46·187**, validation **86,285건**으로 별도 진단기를 준비한다. history_length는 target 직전 실제 관측 사건 수이며 전체 series 길이가 아니다.
- 기존 B 예측 캐시는 checkpoint와 state SHA, 모든 표본 키·수량·순서가 일치할 때만 재사용한다. 검증된 캐시가 없으면 두 고정 모델을 같은 CPU runtime에서 eval/inference 모드로 추론한다. 학습 및 optimizer 갱신을 실행하지 않는다.
- 표본 키 `(oper_part_no, target_position, target_seq)`의 중복·누락·재정렬을 검증하고 원본 identity 및 quantity SHA와 일치시킨다. 비교 열은 `prediction_b`, `prediction_candidate`, 실제 수량, history_length, series 식별자, 각 오차다. 입력 조건 분석용 직전 수량·과거 평균·최근 변동은 target 이전 관측값으로만 계산한다.
- 추론 전 수치 재현 기준을 고정한다. 전체와 기존 수량/이력별 RMSE·MAE·bias를 원본 summary와 `atol=1e-5, rtol=1e-5`로 비교하며, 비유한 값은 허용하지 않는다. 불합격하면 기술적 재현 문제를 기록하고 행 단위 해석으로 넘어가지 않는다. 결과를 본 뒤 허용 오차를 자동 확대하지 않는다.
- 완료 조건: 정확한 86,285개 표본 매칭, 원본 수량·분할·state 불변, 전체 및 구간 지표 재현, held-out 미사용이 확인된다. 상태와 캐시 출처는 별도 receipt에 남긴다. 원본 CUDA 비교표를 CPU 재현값으로 덮어쓰지 않는다.

**수량과 이력의 교차조건을 검증 — 다음 작업 2**

- 다음 15개 셀을 미리 고정한다: 수량 `≤2`, `(2,31]`, `(31,46]`, `(46,187]`, `>187` × 이력 `≤64`, `65–128`, `>128`. 각 셀에 표본 수와 series 수를 표시하고 빈 셀도 숨기지 않는다.
- 셀별 양 모델 MAE·RMSE·bias, 평균/중앙값/분위수 예측 이동, 과소·과대예측 비율, ΔMAE·ΔMSE와 전체 차이 기여를 집계한다. 구간 기여를 합해 전체 수치와 기존 두 주변 분포가 복원되어야 한다.
- 검증 질문 1: 이력65–128의 악화가 수량31–187과 실제로 겹치는가, 아니면 다른 수량 구성으로 설명되는가? 동일 수량별 이력 차이를 대조한다.
- 검증 질문 2: 이력128 초과의 악화는 평균 과대예측 증가, 오차 분포 확산, 특정 수량 구성 중 어디에서 나타나는가? 다른 이력에서의 과소예측과 분리한다.
- 검증 질문 3: (2,31]에서 RMSE 개선과 MAE 악화가 함께 나타나는 이유가 큰 오차 일부의 감소와 다수 작은 오차의 증가인지 확인한다. 평균만으로 판정하지 않는다.
- paired 오차 분해 `ΔMSE = mean(2*error_B*prediction_shift + prediction_shift²)`와 각 모델의 `MSE = bias² + centered MSE`를 계산한다. 두 분해는 서로 다른 질문을 다루며 기여 항을 교차 혼합하지 않는다.
- 이 가설들은 이미 집계를 본 뒤 정한 탐색 가설이다. 교차표를 보기 전에 기록했다고 해서 독립 확증 가설로 취급하지 않는다. 실제 target 수량 구간은 사후 오차 설명에만 사용한다.
- 완료 조건: 15개 셀과 두 주변 분포의 합계가 일치하고, 위 질문별로 지지·반박·미확인을 구분할 수 있다.

**일부 series의 영향과 반복 패턴을 구분 — 다음 작업 3**

- 같은 paired 표본으로 series별 SSE·절대오차 차이를 집계한다. 악화·개선 series 수, 순차이, 양의 악화 총량, 상위1%·5% series의 양의 악화 총량 기여를 각각 표시한다. 순차이를 분모로 한 비중과 혼용하지 않는다.
- 필요 시 고정 seed와 반복 수를 기록한 series 단위 bootstrap으로 조건별 차이의 표본 변동을 보조 확인한다. 모델 선택에 사용한 validation의 재표집이므로 독립 검증·다중 seed 안정성·held-out 성능의 증거가 아니다.
- 완료 조건: 주요 패턴이 소수 series에 집중되는지와 넓게 반복되는지를 구별한다. 추가 train 추론이나 재학습을 자동 시작하지 않는다.

**수정 대상을 좁히는 근거를 정리 — 다음 작업 4**

- 관측 가능한 입력 조건에서도 반복되는 문제가 확인되면 그 조건과 관련된 memory 경로·공통 encoder·quantity head를 후속 검토 대상으로 제안한다. 출력 오차의 상관관계만으로 특정 모듈의 인과적 결함을 확정하지 않는다.
- 일괄 상향 보정은 이력128 초과의 과대예측을 더 악화시킬 수 있으므로 현재 수정안으로 채택하지 않는다. 효과와 악화 여부는 아직 실험되지 않았다.
- Instacart와 비교할 때 같은 비교 상대(B), 동일 지표 정의, 동일 수준의 조건부 근거를 사용한다. Instacart의 RMTPP 대비 bias² 기여를 Intermittent의 B 대비 값과 직접 등치하지 않는다.
- 완료 조건: 확인된 실패 조건, 가능한 설명, 반례와 추가로 필요한 인과 검증을 구분한 수정 검토안이 준비된다. 모델·loss·selector 변경, 새로운 seed·학습·held-out 평가와 최종 채택은 이 진단 준비에 포함하지 않는다.

**작업 순서와 산출물**

현재 세션에서 `동일 표본 복원 → 수치 재현 → 15개 교차조건 → series 집중도 → 수정 검토안` 순서로 직렬 진행한다. 공통 checkpoint·표본·재현 기준에 의존하므로 별도 세션이나 병렬 agent로 분리하지 않는다.

다음 진단의 소형 증적은 `paper/results/intermittent_dual_timescale_quantity_diagnostic_20260910/`, checkpoint와 행 단위 예측은 `search_artifacts/intermittent_dual_timescale_quantity_diagnostic_20260910/`에 별도로 저장할 계획이다. 이번 준비 작업은 이 경로에 새 추론 결과를 생성하지 않았다. 커밋·Push·MR은 수행하지 않았다.
