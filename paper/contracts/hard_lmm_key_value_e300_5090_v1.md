## Execution Safety

`run_hard_lmm_key_value_screening.py` re-audits both e1 artifacts before training,
checks CUDA XML, source and checkpoint digests, and compares all training source
files with the smoke snapshot. Only orchestration/audit code may differ.
Python 3.12.13, torch 2.11.0+cu130, CUDA13.0 and polars1.39.3 must match.

Each dataset is a separate process. Existing output roots are rejected. Before
each run, source/data checks and GPU-idle/GDM-inactive/VRAM/Xid/OOM preflight
repeat. Exceptions record failed status; no automatic resume/retry is permitted.
An hourly heartbeat monitors status/process/source and reports meaningful change,
completion, failure or required action. It must not kill unrelated processes.

The completed-run auditor checks every epoch's full target count, earliest
minimum checkpoint and first legal early stop. It compares the saved best model
with the best state embedded in the last checkpoint, NOT the final model state,
which may legitimately differ. e1 audit behavior remains available separately.
