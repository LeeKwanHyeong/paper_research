# B를 논문의 핵심 방법으로 유지할 근거

## Material Passport

- 유형: 고정된 Validation 실험의 기술통계 해석과 연구 주장 검토.
- 범위: B/shared15·single_mlp·D/encoder_only, 3데이터×3seed=27조건. Test·새 추론·비용 결과를 포함하지 않는다.
- 수치 근거: 같은 폴더의 REPORT.json, REPORT.md, TABLE.csv, PAIRED_SEED_DELTAS.csv. 각각 원본 receipt와 prediction의 절대 경로·split·SHA를 연결한다.
- 사실과 권고를 구분하며 모델·학습·선택 계약을 변경하지 않는다. 아래 해석은 원고 초안이나 학회 게재 가능성 평가가 아니다.

## 판단

현재 Validation으로 B를 범용 정확도 우위의 핵심 방법으로 확정할 근거는 부족하다. B는 연구 후보로 유지하되, 대표 구조의 확정은 보류하는 편이 타당하다. 단일 MLP로 모델 이름만 바꾸면 독창적인 기여가 확보되는 것도 아니다.

이번 비교는 두 질문을 구분한다. B↔D는 이력 보정을 추가하는 효과를, B↔단일 MLP는 보정기가 B의 공유·분기 구조여야 하는지를 평가한다. 단일 MLP는 D보다 전체 수량 RMSE가 9/9 seed에서 낮다. B는 8/9이다. 따라서 이력 보정의 효용에 대한 근거와 B의 특정 설계가 필요한지에 대한 근거를 혼합하면 안 된다.

## 확인된 긍정 근거

- Taxi 큰 수량에서 B는 단일 MLP보다 평균 RMSE 7.0294%, MAE 8.3128%가 낮고, 두 지표 모두 3seed 전부 개선한다. D와 비교해도 3seed 모두 개선한다. 현재 B에 가장 유리한 수량 예측 결과다.
- RAF 전체 시간 NLL은 B가 단일 MLP보다 3seed 모두 낮고 평균 2.2407% 낮다. 같은 데이터의 전체 MAE 평균도 0.2265% 낮다. 그러나 전체 RMSE의 평균은 0.0646% 높으므로 전체 수량 정확도 우위라고 묶을 수 없다.
- B는 D보다 RAF·Taxi 전체 RMSE가 평균 1.1187%·11.4682% 낮다. 다만 단일 MLP도 이 두 데이터에서 개선하므로 이 결과만으로 공유15차원·8분기 설계의 필요성을 입증하지 않는다.

## 유지해야 할 불리한 결과

- B의 전체 수량 RMSE 평균은 MLP 대비 RAF +0.0646%, Taxi +0.6529%, Intermittent +4.6036%다. 세 데이터 평균 모두 MLP가 낮다. 세 데이터의 원래 수량 단위가 다르므로 원시 오차를 한 평균으로 합치지 않는다.
- RAF 큰 수량에서는 B의 RMSE·MAE가 MLP보다 3seed 전부 높고, 평균 +1.6492%·+2.3211%다. 따라서 Taxi 결과를 근거로 큰 수량 일반 우위를 주장할 수 없다.
- Intermittent 전체 MAE는 B가 MLP보다 3seed 전부 높다. seed62에서 B의 전체 RMSE는 1.927407, MLP는 1.644464로 B가 17.2058% 높다. 큰 수량 RMSE는 36.5579%, MAE는 47.0397% 높다. 이 seed를 제외하거나 다른 seed로 교체하면 안 된다.
- 같은 Intermittent seed62의 큰 수량 TimeNLL은 B 10.546195, MLP 4.212819e-7, D 0.923029다. B의 큰 수량 TimeNLL 3seed 평균±SD는 3.642358±5.981930이다. 평균만으로 이 악화를 감추지 않는다. 저장된 개별 TimeNLL을 집계한 것이며, 분포 파라미터에서 이 원인을 새로 진단한 것은 아니다.
- Taxi 전체 시간 NLL은 D 대비 B가 평균 64.3399%, MLP가 45.8081% 높고, 양쪽 모두 3seed에서 악화한다. 수량 개선과 시간 점수의 손실을 함께 제시해야 한다. 수량·시간을 동시에 개선했다는 서술은 성립하지 않는다.

## 가능한 주장과 아직 불가능한 주장

확인 가능한 표현은 특정 구조에 따라 전체 수량·큰 수량·시간 점수 사이의 상충 관계가 달라진다는 것이다. Taxi 큰 수량에 유리한 구조적 편향이 있는지는 탐색적 가설로 남길 수 있다. 이 결과를 보고 Taxi 큰 수량만 핵심 목표로 바꾸고 사전에 정한 목표였던 것처럼 쓰면 안 된다.

보편적 정확도 우위, 효율 우위, 안정성의 원인, 학문적 독창성, 실제 여덟 과거 시점의 별도 활용은 아직 입증되지 않았다. B의 여덟 분기는 동일한 현재·직전 관측 관계를 이력 길이의 가용 조건에 따라 재사용한다. 또한 B·MLP의 보정 파라미터가 각각 9600개라는 사실은 활성 파라미터 수나 함수 집합까지 같다는 뜻이 아니다. MLP는 가용 이력 비트만으로도 보정을 만들 수 있다는 설계 차이가 있다.

같은 선택본·같은 GPU·같은 seed의 비용 검증에서 실질적인 속도·메모리 이득이 확인되면 B를 선택할 추가 근거가 생긴다. 그 경우에도 정확도 손실이 허용 가능한지는 사용 목적에 따라 판단해야 하며, 사후 가중점수를 만들어 승자를 정하지 않는다. 비용 차이가 작거나 B가 더 비싸다면 현재 자료에서 B를 반드시 유지해야 한다는 근거는 약해진다.

## 비교와 일반화의 한계

- 모든 checkpoint는 전체 Validation raw 수량 RMSE의 첫 strict minimum으로 선택됐다. NLL 최적 checkpoint의 비교가 아니며, 같은 Validation을 선택과 구조 판단에 사용했다. 최종 held-out 일반화 근거로 표현하지 않는다.
- 평균±표본SD는 3개 학습 seed의 기술통계다. p-value나 유의성·동등성 검정은 수행하지 않았다. 3seed의 방향 일치만으로 모집단에 대한 우월성을 확정하지 않는다.
- seed42는 5080, seed52/62는 5090에서 실행됐다. 각 seed의 모델 간 비교는 같은 GPU이지만, seed 효과와 GPU/수치 환경 효과를 이 배치만으로 분리할 수는 없다. cuDNN은 각각91900/92000이다. 비용의 절대 시간은 두 GPU 사이에 섞지 않는다.
- 큰 수량은 Train의 마지막 경계를 넘는 관측(q>200/3449/187)이며, Validation 표본 수는 RAF50/6690, Taxi79/8268, Intermittent1141/86285다. 다른 데이터·기간에서 같은 효과가 재현될지는 미확인이다.
- Taxi 큰 수량의 TimeNLL은 모두 극소 양수다. 반올림한 0을 정확한0이나 완벽한 시간 예측으로 해석하지 않는다. 극소 분모의 상대차이는 실질적 효과로 해석하지 않는다.

## 통계 해석 오류 점검 — 11/11 항목 검토

| 항목 | 이번 분석에서의 처리와 남은 한계 |
|---|---|
| Simpson 역설 | 단위가 다른 데이터는 합치지 않는다. seed 승수와 평균 차이의 방향이 다를 수 있음을 보존한다. 이를 곧바로 Simpson 역설로 명명하지 않는다. |
| 생태학적 오류 | seed 평균에서 개별 사건·다른 데이터 모집단의 효과로 일반화하지 않는다. |
| Berkson 선택 편향 | Validation·과제의 고정 모집단 안에서 비교한다. 이 표로 표본 선택 편향이 없다고 입증하지 않는다. |
| Collider 편향 | 새로운 조건부 공변량 조정은 하지 않는다. Validation 선택 조건의 영향을 별도로 제한한다. |
| 기저율 무시 | 전체·큰 수량의 실제 개수와 Train 경계를 보고한다. 진단 분류의 민감도·특이도 주장은 해당하지 않는다. |
| 평균으로 회귀 | 극단 seed를 제외하거나 재학습하지 않는다. 전후 효과나 원인으로 해석하지 않는다. |
| 생존자 편향 | 27조건 전체를 포함한다. 학습 진입 전 설정 실패와 0 optimizer 기록은 원본으로 보존돼 있으며 성공한 과학 seed를 골라 대체하지 않았다. |
| 다중 탐색 효과 | 세 쌍×3데이터×3seed×2범위×3지표의162차이를 모두 제공한다. 유의한 결과만 선별하거나 승패 점수로 합산하지 않는다. |
| 분석 경로 선택 | 계약은 학습 전에 고정됐다. Taxi 큰 수량 특화 해석은 결과를 본 뒤의 탐색적 관찰이라고 구분한다. |
| 상관과 인과 혼동 | 통제된 구조 비교의 결과를 기능적 차이와 연결하되, 공유 차원이나 분기 각각이 원인이라는 기제 주장을 하지 않는다. |
| 역인과 | 예측 결과를 사건 발생의 인과 설명으로 사용하지 않는다. 시간적 인과 추론 분석은 수행하지 않았다. |
