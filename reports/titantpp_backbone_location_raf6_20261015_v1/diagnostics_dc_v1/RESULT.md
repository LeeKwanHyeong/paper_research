# RAF 기존 CNN의 잔차 계수 합 검사

선택 checkpoint3의 텐서만 읽었다. 모델 생성·forward·추론·학습·Test·원격 호출은 없다.
완전한 세 관측의 동일 투영값 x에서 잔차는 (w0+w1+w2)x, 원래 값까지 더한 출력은 (1+w0+w1+w2)x다.
