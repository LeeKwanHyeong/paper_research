# 3개 GPU 시간별 모니터

**5080·5090·A100을 매시간 확인한다 — 완료**

- 기존 A100 heartbeat를 **TitanTPP 5080·5090·A100 시간별 모니터**로 갱신했습니다. 동일 채팅에서 1시간 간격으로 활성화돼 있고 중복 모니터를 만들지 않았습니다.
- 대상은 5080 Taxi·RAF 폭8/12의12조건, 5090 Intermittent 폭8/12의6조건, A100 CNN·GRU seed42의9조건입니다. 두 캠페인을 별도 집계합니다.
- 기존 학습과 과학 계약은 변경하지 않았습니다. 관측 중 새 학습·재시작·재개·임대·프로세스 종료를 실행하지 않습니다.

**실제 서버 관측과 종료 판정을 검증한다 — 완료**

- 새5080/5090 읽기 전용 관측기와15개 focused test를 추가했습니다. 고정 계약·114소스 SHA와 원격 읽기 스크립트 문법 검사가 통과했습니다.
- 세 대상에서 각각 한 번의 실제 SSH 관측이 성공했습니다. 소유 PID·GPU UUID·저장 epoch 및 terminal·소형 기록 SHA·selected/last Validation replay를 함께 확인합니다. 원본 binary 해시·회수·CPU 재추론 감사는 별도입니다.

| 대상 | 실제 KST 관측 | 완료 | 진행 | 대기 | 실패·미확정 |
|---|---|---:|---:|---:|---:|
| 5080 | 10/4 19:17:08 | 12/12 | 0 | 0 | 0 |
| 5090 | 10/4 19:17:09 | 1/6 | 1 | 4 | 0 |
| A100 | 10/4 19:17:12 | 0/9 | 3 | 6 | 0 |

- 5080은12조건과 서버 terminal이 모두 검증됐습니다. 보존된 종료 증거를 재사용해 이후 반복 SSH를 끝냅니다. 완료 당시 남은 과거 worker PID 선언과 실제 소유 프로세스 부재는 새 실패로 해석하지 않습니다.
- 5090은 Intermittent/폭12/seed42 저장14·best12입니다. A100은 CNN+MLP16의 Taxi29/best29, RAF49/best16, Intermittent2/best2가 저장됐습니다. 이것은 위 시각의 관측이며 이후 상태를 보장하지 않습니다.
- 전체 큐 ETA는 미시작 모델의 자체 실측과 대기시간이 없어 미확정입니다. 조건부 fit ETA는 최근 최대10개 epoch 중앙값과 best 미갱신 가정으로 계산하고, binary 회수·CPU 감사 시간을 제외합니다.

**나머지 실행과 원본 회수를 확인한다 — 진행 중**

- 5090·A100을 매시간 확인하고 진행·오류·조건부 ETA를 한국어 표로 알립니다. 한 서버 조회 실패가 다른 서버 관측을 막지 않습니다.
- 종료된 대상은 검증한 실제 시각의 증거를 재사용합니다. 모든18+9조건과 서버 terminal, A100 원본 SHA 회수·비용보고·Pod 삭제/목록부재를 확인한 뒤 이 통합 heartbeat만 종료합니다. CPU 감사가 남으면 따로 표시합니다.

실행 지침은 [SCHEDULER](SCHEDULER.md), 앱 설정과 초기 관측 SHA는 [scheduler receipt](scheduler_receipt.json)에 있습니다. 세 서버의 원본 관측은 각 bundle의 hourly_monitor에 보존하며 [5080](initial_5080_analysis.json), [5090](initial_5090_analysis.json), [A100](initial_A100_analysis.json) 분석본을 함께 기록했습니다.
