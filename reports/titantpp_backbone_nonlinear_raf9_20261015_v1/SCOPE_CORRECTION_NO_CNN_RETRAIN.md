# 사용자 범위 정정: 기존 CNN 재학습 제외

2026-10-15 최신 사용자 지시: “잠깐 기존 CNN기준선은 건들지마 뭘또할라그래 그거 중요하지않아”

이 정정은 기존 SCHEDULER.md와 EXPERIMENT_PLAN.md의 신규 CNN 재학습3개 및 총9개 실행 계획보다 우선한다. 과거 계획과 실패 기록은 지우지 않는다.

- 기존 CNN 모델·checkpoint·Train/Validation/Test 결과는 수정하거나 재학습·재평가하지 않는다. 검증된 기존 결과를 읽기 전용 비교 기준으로 재사용한다.
- 새 RAF 학습은 채널별 비선형 대조군과 시점·채널 결합 비선형 후보 × seed42/52/62, 총6개다. 5090 최대3병렬을 유지한다.
- 같은5090 CNN 재학습, 새 기준선 만들기, 기존 CNN 결과 교체는 제외한다. 과거 CNN과의 Runtime 차이는 보고의 한계로만 명시한다.
- 범위 정정 시점에 신규 RAF 원격배포·학습은 아직 시작하지 않았다. 이전9개 계약·스크립트는 현재 실행 대상으로 사용하지 않는다.
- 6개에 맞는 계약·실행·관측·종료·Validation6/Test6 평가와 검사를 정리하고 검증한 뒤에만 후보 학습을 시작한다. 실행 중인 기존5080 Taxi 작업에는 개입하지 않는다.
- 사용자 성능 기준, 외부 비교군 검증, 불리한 결과 보존, Notion 누적 기록, RAF 통과 후 동일 구조의 Taxi/Intermittent 조건부 확장 및 backbone 개선 목표는 유지한다.
