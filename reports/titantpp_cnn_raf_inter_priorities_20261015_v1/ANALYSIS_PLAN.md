# RAF·Intermittent CNN 후속 후보 근거 분석

Material Passport: academic-research-suite / experiment-agent / validate; 2026-10-15; v1.

## 범위와 현재 기준선 — 완료

사용자 요청: Taxi 학습과 별도로 RAF·Intermittent에 필요한 개선을 기존 Train·Validation 결과로 분석한다. 새 학습·추론·원격 조회·Test·혼합 성과·원고 열람은 하지 않는다. 기존 CNN의 alpha=1 저장 예측, 기존 메모리 감쇠 진단, 관측 조건 매칭 분석을 사용한다. 원본 및 실행 중인 Taxi 계약·파일·자동화는 바꾸지 않는다.

기존 분석에서 RAF의 실제 큰 수량 오류 집중 및 매칭 표본 부족, Intermittent의 관측 하락 조건 과소예측을 이미 확인했다. 아래 추가 집계는 이 사실을 본 뒤 설계한 탐색이다. 확인적 검정이나 사전등록으로 표현하지 않는다.

## 원본과 재집계 일치 확인 — 다음 작업

기존 receipt/analysis SHA와 실제 사용 예측 part SHA를 확인한다. 각 데이터셋·split에서 세 seed의 대상·수량·관측 이력이 같은지 검증한다. 전체 및 큰 수량 여섯 지표를 기존 집계와 수치 대조한다. 합계/분해 일치도 검사한다.

## 데이터셋별 오류와 관측 가능한 단서 — 다음 작업

- 기존 Train 사분위 경계로 마지막 관측 수량·이력 표준편차·변화 크기를 나눈다. Validation에서 경계를 다시 정하지 않는다.
- 이력 길이 1 / 2–3 / 4–8 / 9–32 / 33 이상으로 비교한다. 직전 수량 및 관측 이력 평균은 저장값만 재집계하며 학습하지 않는다.
- RAF q>200, Intermittent q>187은 기존 Train 고정 큰 수량 기준이다. target 큰 수량·target 변화 방향은 사후 오류 설명에만 쓰며 입력·gate·조건 선택 정보로 쓰지 않는다.
- 각 구간의 행/개체 수, raw RMSE·MAE·bias(예측−실제), 과대/과소 비율, SSE 기여, TimeNLL을 모두 남긴다. 빈 구간을 숨기지 않는다.
- 큰 수량 오류가 과거 높은 수준·변동폭에서 포착되는지, 오류가 몇 개 개체에 집중되는지 확인한다. Test를 보지 않은 채 관측 요약 특징만으로 판단하며 예측 불가능성은 증명하지 않는다.
- Intermittent의 방향별 Train→Validation MSE 차이를 구성비 변화 항과 동일 방향 내부 MSE 변화 항으로 대수 분해한다. 인과 분해로 해석하지 않는다.
- 기존 같은 개체·수량·변화 폭 매칭 결과를 유지하며 RAF의 0개 공통 표본을 차이 없음으로 해석하지 않는다.

## 후보와 한계 정리 — 다음 작업

공통 입력·손실·head·메모리를 유지하는 CNN 내부 변경을 우선 후보로 제시한다. 근거가 있는 오류와 원인이 미확인인 부분을 구분하고, 후보별 대조군·평가 구간·기각 조건을 기술한다. 새 모델 구현·학습 실행 계약은 이번 범위에 포함하지 않는다. 기존 Test를 본 뒤의 탐색이며 3seed SD는 같은 데이터의 학습 변동이다. 효과·인과·일반화 개선·통계적 유의성은 아직 미확인이다.
