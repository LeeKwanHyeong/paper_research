# 현재 연구 기준선과 남은 판단

기준일: 2026-10-19. 시간 가중치0·0.1·1·10의 최종 Validation 비교를 반영한다. 이 문서는 과거 중간 관측을 현재 상태로 대체하며, 당시 원본 기록은 보존한다.

**현재 기준선을 고정한다 — 완료**

- 현재 사용 데이터는 Cap이다. Train Q3로 정한 상한은 Taxi65·RAF10·Intermittent20이며, 관측 수량 이력과 정답 수량에 같은 상한을 적용했다. 이전 자료는 상한 적용 전 데이터로 구분한다. 두 자료의 raw 오류 차이는 같은 예측 문제에서의 모델 개선량이 아니다.
- 현재 손실 비교의 고정 모델은 이력 MLP16이다. 단순 독립 MLP가 아니라 Titan attention·이력 MLP 보정·정적 메모리·공통 수량/시간 head를 포함한다. MLP16이 세 데이터셋의 최우수 백본으로 확정됐다는 뜻은 아니다.
- 기준 조건은 시간 가중치1, seed42·52·62다. 입력 log1p·수량 log-MSE·head·메모리·학습 예산·선택 기준은 유지했다. 전체 Validation 실수량 RMSE의 최초 strict finite 최소 epoch를 선택하고, MAE와 TimeNLL도 같은 checkpoint에서 비교한다.
- 기존 CNN 및 저장된 기준 모델·checkpoint·결과는 변경·재학습·재추론하지 않았다.

**백본·데이터·목적함수의 문제를 구분한다 — 분석 완료 / 원인 미확정**

1. 상한 적용 전 MLP4·MLP16·두 구조 대조군의 저장 Train/Validation 분석에서, 폭 확대나 이력 보정 분기 확대가 세 데이터셋을 함께 개선하지 않았다. Cap36에서도 지표별 우세 구조가 달랐다. 모델이 데이터보다 복잡하다는 설명은 가능성이며 입증된 공통 원인이 아니다.
2. 큰 수량 오류의 방향과 빈도는 데이터셋별로 달랐다. Cap Taxi의 상한 도달 집단은 나머지보다 평균 MAE가 낮았고, RAF는 상한 수량의 과소예측이 남았다. 큰 수량은 모두 예측 불가능하거나 log1p 입력이 잘못됐다고 결론내릴 수 없다.
3. 수량 학습은 log 공간 제곱오차, 평가는 실수량 RMSE·MAE다. 이 목적 차이와 공유 백본에 함께 작용하는 시간 손실을 구분해야 한다. 제한된 Train 배치의 기울기 진단에서도 시간 손실의 영향력이 모든 데이터셋에서 더 크지는 않았다. 실수량 손실은 기울기 진단만 완료했고 재학습 비교는 하지 않았다.

**같은 백본에서 시간 손실의 영향을 확인한다 — 학습·회수·Validation 비교 완료**

시간 가중치0.1·10의 신규18개와0의 신규9개가 모두 종료했다. 선택 checkpoint의 native Validation27개 재현과 원본 회수·SHA 검증을 마쳤다. 기존 가중치1의9개를 재사용해 총36개를 비교했다. 신규 fit27개와 Validation 재현27개의 실제 child exit0, dispatcher4개의 실제 exit0를 확인했다. wrapper 자신의 OS exit를 별도 직접 관측했다고 표현하지 않는다.

가중치0에서도 시간 관측 입력과 공유 백본은 학습에 사용한다. 시간 손실을 backward에서 제외했고, 시간 전용 head9개의 불변 증적을 확인했다. 그 조건의 TimeNLL은 미학습 시간 head의 진단값이며 물리 시간 예측 MAE/RMSE가 아니다. Intermittent0의 TimeNLL은1.808732로 기준1의0.315344보다 높다. 이를 숨기거나 공동 수량·시간 예측의 우세로 해석하지 않는다.

이 결과는 목적함수의 상대 가중치에 따른 성능 차이다. 백본 구조의 개선·유일한 gradient 충돌 원인·통계 유의성·Test 일반화의 증명이 아니다. 이번 가중치 조건의 새 Test는 실행하지 않았다.

**두 서버와 외부 비교군 상태를 구분한다 — 신규 학습 종료 / 외부 작업 일시정지**

- 실제 관측2026-10-19 07:59:42/43 KST(가중치0)와08:00:12 KST(0.1·10)에서 양쪽 학습 및 Validation pipeline의 완전 종료를 확인했다. 현재 이 작업에 남은 학습은0개다.
- S2P2·RMTPP·THP의 Cap27은 사용자의 일시정지 지시가 유지된다. 학습 완료11·정지6·미시작10이며,11은 Test 완료 수가 아니다. 같은 dispatcher/worker 신원과 T 상태를 다시 확인했으며 재개하지 않았다. 정지 CUDA context가 남아 있으므로 전역 GPU가 비어 있다고 표현하지 않는다.
