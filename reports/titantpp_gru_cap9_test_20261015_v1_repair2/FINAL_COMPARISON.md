## 해석 점검 (11개 항목)

1. Simpson 역전: 데이터셋을 합치지 않고 seed별 차이까지 제시했다.
2. 생태학적 오류: 평균에서 개별 대상·모든 seed의 개선을 추론하지 않는다.
3. 선택 편향: 고정 데이터셋·Validation 선택 조건의 결과이며 모집단 전체로 확장하지 않는다.
4. Collider 편향: 추가 변수 통제나 인과 효과 추정을 수행하지 않았다.
5. 기저율 무시: 분류 확률 해석은 해당하지 않으며 큰 수량 지표를 전체와 분리했다.
6. 평균 회귀: 이전 Test 악화 뒤 설계한 후속 후보이므로 개선을 독립 확증으로 해석하지 않는다.
7. 생존자 편향: 승인된 CAP9 전부와 CNN/FULL18을 포함했다. 실패 기록을 삭제하지 않았다.
8. 다중 탐색: 여섯 지표와 모든 seed를 보존하며 유리한 지표만 선택하지 않았다.
9. 분석 선택의 자유도: Test 노출 뒤 설계된 탐색적 후속이라는 이력을 명시했다.
10. 상관과 인과: GRU 용량이 반전의 원인이었다고 확정하지 않는다.
11. 역인과: 인과 방향을 추정하지 않는 기술적 성능 비교다.

p값·신뢰구간·통계적 유의성을 산출하거나 주장하지 않았다. 표본SD는 같은 데이터 분할에서 학습 seed 3개의 산포이며 데이터셋 불확실성 전체를 나타내지 않는다.
