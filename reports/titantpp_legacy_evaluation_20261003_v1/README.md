# 기존 네 데이터 분할의 동결 모델 재평가

## 목적과 승인

2026-10-03 사용자가 기존 평가 범위 고정, 전체 처리 검증, 실제 평가 및 원고
반영의 세 단계를 인용하고 “진행하자. 승인할게”라고 승인했다.
이번 경로는 `retrospective_locked_test_reevaluation`이다. 기존 test 분할을
평가하며 새 미접근 독립 자료를 확보했다는 주장을 하지 않는다. Taxi 2월 등
새 자료 확보와 추가 접근 이력 조사는 이번 필수 선행 작업에 포함하지 않는다.

기존 MLP·외부 encoder 6개·구조 대조 2개에 각각 seed42/52/62를 적용한
108개 selected checkpoint와 직전/관측창 평균 수량 기준선을 평가한다.
Deep Renewal은 기존 사용자 결정대로 원고 비교에서 제외하지만 기존 연구
기록을 보존한다. A100 후보는 이번 대표 모델로 승격하지 않는다.
새 학습·기존 선택 epoch 변경·test 기반 설정 변경·새 유료 임대는 없다.

## 고정 모집단

| 데이터 | 기존 test 대상 수 | 관측 이력 창 / 최대 행 |
|---|---:|---|
| Taxi | 8,327 | 168시간 / 256 |
| Intermittent | 88,019 | 520주 / 256 |
| Instacart | 578,387 | 52일 / 64 |
| RAF | 5,226 | 84개월 / 84 |

기존 분할과 모든 적격 개체를 유지한다. 첫 이벤트는 단독 예측 대상이 아니며,
모든 방법은 같은 대상과 허용 이력을 받는다. 앞선 test 이벤트는 해당 이벤트가
이미 관측된 다음 시점부터 과거 문맥으로만 제공한다. target 수량은 가리고,
예측은 직전 관측 상태에서 만든다. test로 정규화나 모델을 다시 맞추지 않는다.

RAF의 이전 배포본은 train/validation 전용이므로 원래 전체 분할 파일을 연결했다.
train/validation 행은 모든 열에서 이전 배포본과 일치한다. Intermittent의
이동 날짜는 사용자가 확인한 보안·비식별화 처리이며 실제 미래 관측이 아니다.
날짜 이동 확인은 미접근 독립 평가나 재배포 권한의 증명으로 취급하지 않는다.

## 검증과 실행

`prepare.py`는 파일 SHA, 분할과 정렬된 개체/시점 키를 고정한다.
`evaluate.py`는 각 조건의 원래 동결 소스를 별도 프로세스에 가져오며,
배치128 추론을 최대8,192행 Parquet 조각으로 저장한다. 전체 입력 로더는
메모리에 올라가므로 로더 생성의 메모리도 실제 환경에서 확인한다.
`analyze.py`는 모든108개 완료 영수증과 정확한 모집단 일치를 확인한 후
단위별 오차 합으로 고정된 paired bootstrap을 계산한다. 누락 조건이나 실패를
유리한 부분집합으로 제거하지 않는다.

5080의 기존 ai_env를 공용 소스 수정 없이 별도 artifact root에서 사용한다.
동시 추론1개, GPU12GiB/RSS32GiB, 조건3시간·전체24시간의 상한을 둔다.
추가 임대료는0이며 다른 서버나 Pod를 사용하지 않는다. 원격 CUDA 실행 전에
코드·계약을 동결하고, CPU/CUDA validation 표본36조건과 대표MLP 네 데이터의
전체 validation replay가 통과해야 test를 시작한다.

주 분석은 기존 기준대로 이벤트 가중 지표의3seed 평균이며 seed 표준편차는
표본 표준편차다. 불확실성은 고정된 학습seed를 조건으로 한 평가 표집 범위다.
Taxi는168시간 공통 달력 블록, Intermittent는사업장, 나머지는개체로 재표집한다.
시간 구간이 부족한 Taxi의 주 신뢰구간을 억지로 계산하거나 민감도 분석으로
대체하지 않는다. 모든 비교와 실패를 보존한다.

## 현재 상태

모집단·원본 연결은 완료. 로컬 실행기·통계 테스트를 마치고 5080 validation
검증을 준비한다. 실제 test 완료 여부는 `runs/test/attempt1/terminal_manifest.json`,
분석 완료 여부는 별도 최종 분석 영수증으로 판단한다.

기존 준비 보고서의 승인 전·독립 모집단 미확정 기록은 과거 증적으로 보존한다.
이번 범위와 승인에는 이 폴더의 `execution_contract.json`을 적용한다.
