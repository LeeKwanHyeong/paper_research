# MLP16 현재 관측 직접 경로: 18개 학습 준비

현재 손실·시간 입력 비교가 모두 끝나면 공통 조건 하나를 선택하고, 두 후보를 Cap Taxi·RAF·Intermittent 각각 seed42·52·62로 학습한다. 기존 CNN과 이전 실험은 변경하지 않는다.

**현재 기준선 — 완료**

- 기존 MLP16과 두 후보의 공통 구조·초기화·추가 용량을 고정했다. 관측 후보는 Encoder 뒤에 현재 관측 임베딩을 직접 전달하며, 이력 대조는 같은 위치에 같은 크기의 이력 변환 경로를 둔다. 두 경로는 기존 메모리 앞에 들어간다.
- 합성 입력으로 두 후보×시간 입력2종×수량 손실3종의 학습·저장·재현을 확인했다. 통합 검사114개와 하위 검사115개가 통과했다. 실제 GPU 검증과 새 학습은 아직 수행하지 않았다.
- 초기 실패는 검사 자료와 모듈 캐시를 격리하는 코드의 오류였다. 실패 원문과 수정 뒤 통과 원문을 local_checks_v1에 보존했다. 실제 학습 실패로 집계하지 않는다.

**이전 비교가 끝나기를 기다린다 — 외부 작업 대기**

- 기존 손실18와 이어지는 원시간27의 종료·원본 회수·Validation 재현을 확인한다. 완료된 두 비교의54개 결과를 로컬 원본에서 검증하기 전에는 새 원격 작업을 하지 않는다.
- 시간 log1p/원간격×수량 log-MSE/실수량 MSE/실수량 MAE의6개 조건 중 하나를 고른다. 데이터별3seed 평균 RMSE를 고정 log시간·log손실 기준선으로 나눈 뒤 세 데이터에 같은 가중치를 준 평균이 가장 낮은 조건을 선택한다. MAE 비율과 명시된 고정 순서는 동률 처리에만 쓴다.
- 여섯 조건 전체를 보존한다. 공통 조건의 선택은 모든 지표 개선이나 독립 검증을 뜻하지 않는다.

**동일 조건의 두 후보를 학습한다 — 다음 작업**

- 5080에8개,5090에10개를 배정하고 서버당 최대3개씩 병렬로 학습한다. 시간 가중치0·수량 입력 log1p·공통 head·메모리·학습 예산과 기존 기한을 유지한다.
- 실제 유휴·GPU·Runtime·입력·후보 동시 실행 검증 뒤 전용 경로에서 처음 한 번 시작한다. 기존 외부 비교 작업은 재개하지 않는다. 실패 시 자동 재시도·재학습·기한 연장은 없다.
- 전체18개 학습과 선택 checkpoint의 Validation18을 마친 뒤 원본을 서버별 한 번 회수한다. Test는 실행하지 않는다.

**같은 조건의 저장 MLP16과 비교한다 — 학습 뒤 다음 작업**

- 선택된 공통 조건의 기존 MLP16 저장9개와 후보18개를 비교한다. 데이터별3seed 평균±표본SD와 모든 seed의 관측−MLP16·이력−MLP16·관측−이력 RMSE/MAE 절대·상대차이, 악화를 함께 보고한다.
- 여섯 수량·시간 지표를 보존한다. 상한 초과 집단은 Cap 데이터에서 비어 있으므로 N/A다. 시간 head는 학습하지 않아 시간 지표는 진단값이다.
- 후속 처리는 이번18개만 수행하는 유한 작업이다. 반복 개선 스케줄러는 만들지 않는다.

실제 준비 상태와 프로세스 연결은 LOCAL_READY.json과 FOLLOWUP_STARTED.json, 세부 조건은 SCIENCE_SPEC.json과 EXPERIMENT_PLAN.md를 따른다. 대기 상태를 새 학습 시작이나 완료로 표현하지 않는다.
