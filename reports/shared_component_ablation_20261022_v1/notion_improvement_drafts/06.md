이 페이지는 주장과 반증을 함께 관리합니다. 학회의 채택 가능성을 판정하는 문서가 아닙니다.

# 독창성은 어디에 있는가?

정적 조회와 공유 이력 보정의 구성·적용 위치·수량 예측 효과를 검증합니다. **미확정:** 문헌상 새로운 조합인지, 단순한 보정기보다 설계상 이점이 있는지. 이름을 바꾸거나 특정 선행모델의 이름을 본문에서 빼는 것만으로 독창성이 성립하지 않습니다. 관련 구현·아이디어에 실제 의존한 부분의 출처를 누락하지 않습니다.

# 두 모듈이 각각 필요한가?

A–B·A–C·B–D·C–D가 직접 근거입니다. A–D 하나의 차이만으로 둘 다 필요하다고 하지 않습니다. 모델 크기도 바뀌므로 ‘순수 기전’ 해석은 제한합니다. 15차원 공유나8분기의 개별 효과는 별도 질문입니다.

# 외부 비교군보다 항상 정확한가?

아닙니다. 기존 A의 5seed 평균에서는 Taxi·Intermittent 수량 오차가 낮지만 RAF MAE와 일부 seed는 불리합니다. 시간 지표도 일관된 우세가 아닙니다. 전체 표와 seed별 악화를 보존하고 평균 차이를 유의성으로 바꾸지 않습니다.

# 빠르고 메모리가 적은가?

새 A–D 측정 결과 대기입니다. 같은 GPU·선택본·입력에서 학습/평가를 나눠 보고합니다. 과거 MAC 변형 대비 평가 메모리 증가는 보존하며 ‘전반적 메모리 우세’를 주장하지 않습니다. 파라미터 감소와 실측 메모리 감소는 다른 주장입니다.

# 기존 A 재사용이 비교를 왜곡하지 않는가?

학습 조건·source·입력·선택본·실제 종료·Validation 재현을 감사했습니다. 같은 GPU로 배정된6개만 학습 재사용하고 새 Validation/Test를 수행합니다. 5080 배정 A3개는 새 학습입니다. 과거 A3병렬 총훈련시간은 새 단독 시간과 직접 비교하지 않습니다.

# 왜 MAC을 주비교에서 보류하는가?

이전 이벤트용 MAC 변형은 원논문 백본의 충실한 재현 근거가 아니었습니다. 기존 수치와 불리한 결과는 보존하며 원논문 MAC 대비 성능 주장에는 쓰지 않습니다. 현재 승인된 핵심 검증은 A–D입니다. 충실한 MAC 실험은 보류 상태이며 결과가 나쁘다는 이유로 실패·기록을 삭제하지 않습니다.

# 반복해서 확인한 Test 결과는 어떻게 해석하는가?

현재 구현의 Train 학습→Validation 선택→고정 Test 평가 경계는 확인했습니다. 과거 Test 결과를 확인했다는 사실만으로 Test 튜닝을 단정하지 않습니다. 다만 이미 관측한 같은 Test를 사용하는 후속 비교이므로 최초의 독립된 비공개 Test 검증처럼 설명하지 않습니다. 5seed는 독립 Test 집합을 늘리지 않습니다. A–D도 네 사전 지정 구조·모든 seed를 보고하고 Test로 아키텍처를 다시 고르지 않습니다.
