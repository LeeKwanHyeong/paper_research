# 비교 범위와 한계

- 기존 외부 Validation 54개는 선택 checkpoint의 저장 요약·history 근거입니다. 개별 예측·대상 identity·큰 수량 지표의 재현 수준이 제안모델과 동일하게 확인된 것은 아닙니다.
- 기존 3seed와 추가 2seed의 실행 환경·출처를 보존합니다. 기존 A 학습·Validation은 5090/cuDNN92000, 기존 A Test와 추가 2seed는 5080/cuDNN91900입니다. 이 표 전체가 동일 GPU에서 나온 비교는 아닙니다.
- 같은 Test를 반복해 확인한 탐색적 후속 연구라는 한계를 유지합니다. 이번 실행의 Train 학습→Validation 선택→고정 Test 경계는 확인됐으나, 5seed가 새로운 독립 Test 집합 5개를 만드는 것은 아닙니다.
- 외부 원논문의 고유 head·목적함수·모든 튜닝을 능가했다는 뜻은 아닙니다. 성능이 유리해 보이도록 5seed를 3seed로 바꾸지 않습니다.
