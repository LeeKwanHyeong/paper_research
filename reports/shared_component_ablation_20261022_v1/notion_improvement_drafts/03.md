# 네 조합과 통제 조건

| 구분 | 정적 prototype | 공유 이력 보정 | 묻는 질문 |

# 비교별 해석

| 비교 | 분리하는 효과 |
| --- | --- |
| A ↔ B | 보정기가 있는 상태에서 prototype의 추가 가치 |
| A ↔ C | prototype이 있는 상태에서 보정기의 추가 가치 |
| B ↔ D | prototype 없이 보정기가 주는 효과 |
| C ↔ D | 보정기 없이 prototype이 주는 효과 |

A↔D만으로 각 모듈의 필요성을 주장하지 않습니다. 모듈 제거로 파라미터 수도 달라지므로 관측된 효과를 용량과 무관한 순수 기전 효과로 단정하지 않습니다. 공유 15차원이나 8분기 자체가 최적이라는 주장도 이 네 조합만으로 증명되지 않습니다.

# 학습과 재사용

원본 세 데이터 × 공통 seed42·52·62 × 네 구조 = 36조건입니다. seed42는 5080, seed52·62는 5090에 배정하며 같은 데이터·seed의 네 구조는 같은 GPU에서 비교합니다.

A의 기존 source·입력·선택 tensor·history·실제 종료·Validation 재현 증거를 감사했습니다. 같은 5090에 배정된 A 6개 학습은 재사용하고 새 Validation/Test를 만듭니다. 5080의 A 3개와 B/C/D 27개는 새로 학습하므로 신규 학습은 30개입니다. 학습된 A에서 모듈을 끄는 방식으로 B/C/D를 대신하지 않습니다.

# 선택과 보고

batch128, 최대300·최소40 epoch, patience40, AdamW 학습률0.001·weight decay0.01·clip1을 고정합니다. 공통 손실은 시간 NLL + 수량 log-MSE입니다. 전체 Validation 원 단위 수량 RMSE의 최초 strict finite 최소를 선택합니다.

선택본 36개의 개별 Validation 재현과 종료 검증을 모두 통과한 뒤 고정 Test36개를 평가합니다. 전체·큰 수량 RMSE/MAE, recorded TimeNLL, 모든 seed의 절대·상대 차이와 악화를 보고합니다. 평균±표본SD(ddof1)는 훈련 seed 변동입니다. Test를 보고 seed나 구조를 바꾸지 않으며 사전 지정한 네 구조를 모두 남깁니다.
