**상태: A–D 비용 계약 확정, 새 측정 결과 대기.** 정확도와 비용을 같은 선택 checkpoint에 연결합니다. 과거 이벤트용 MAC 변형의 비용 수치를 A–D 결과로 옮기지 않습니다.

# 같은 조건으로 측정하는 방법

| 항목 | 고정 조건 |
| --- | --- |
| 측정 모델 | Validation으로 선택한 checkpoint의 메모리 사본 |
| 입력 | Train 전용 공통 batch128, 준비 seed42 |
| 반복 | 예열5batch 후32batch 측정, 학습·평가 각각 fresh process 3회 |
| 배치 | 같은 데이터·훈련 seed의 A–D는 같은 GPU |
| 보호 | 원본 checkpoint를 저장·변경하지 않고 전후 동일성 확인 |
| 총 측정 | 36조건 × 2경로 × 3반복 = 216개 |

# 정확도와 나란히 볼 비용

| 평가 대상 | 지표 | 해석 범위 |
| --- | --- | --- |
| 학습 계산 | 지연시간, 처리량, 최대 allocated/reserved GPU 메모리 | 정해진 공통 batch에서의 학습 비용 |
| 평가 계산 | 지연시간, 처리량, 최대 allocated/reserved GPU 메모리 | 같은 선택본·입력의 평가 비용 |
| 모델 크기 | 전체 파라미터 수, 제거된 모듈 파라미터 수 | 속도·실측 메모리와 별도 지표 |
| 실제 학습 경과 | 전체 fit 시간, 완료 epoch와 상각 시간 | 과거 A 3병렬 시간과 신규 단독 시간은 분리 |

GPU 메모리는 MiB로 표시하고 allocated와 reserved를 구분합니다. 다른 보존 작업의 예약 메모리는 측정 모델 자신의 allocator 메모리와 별도로 적습니다. 5080과 5090의 절대 시간을 한 평균으로 합치지 않습니다. GPU·훈련 seed별 결과와 같은 장치의 A 대비 차이를 우선합니다. 시간 반복3회는 훈련3seed와 다른 반복입니다.

# 주장할 수 없는 범위

짧은 batch 측정만으로 수렴까지 총비용, 같은 정확도를 달성하는 데 드는 비용, 모든 sequence 길이에서의 우위를 주장하지 않습니다. 전체 경과시간÷완료 epoch는 Validation·저장을 포함한 epoch당 상각 시간이며 순수 학습 시간이나 최근 epoch 속도가 아닙니다.

prototype 제거는 4,096개, 이력 보정 제거는 9,600개의 파라미터를 줄입니다. 그 비율이 전체 GPU 메모리 절감률은 아닙니다. A–D 정확도와 실제 측정을 함께 보고 유지할 모듈을 판단합니다.

# 과거 결과의 위치

이전 동일5090 이벤트용 MAC 변형 비교에서는 A의 학습 메모리는 낮고 평가 메모리는 높았습니다. 따라서 ‘메모리 전반 우월’은 기존 근거로도 성립하지 않습니다. 그 모델은 원논문 MAC의 충실한 백본 비교가 아니므로 원논문 대비 효율 근거로 사용하지 않습니다. 이전 수치는 역사 기록으로 보존합니다.
