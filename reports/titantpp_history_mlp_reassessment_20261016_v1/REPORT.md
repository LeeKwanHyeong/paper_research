# 이력 MLP 폭16 재검토: Taxi의 이득과 RAF의 한계

Verification Status: **ANALYZED**. 저장된 고정 checkpoint 결과의 재집계·코드 대조이며 모델 재현 실험이 아니다. 분석일2026-10-16. 새 학습·추론·GPU 접속·자동화 변경·기존 CNN 변경 모두0.

## 결론

**이력 MLP를 다시 출발점으로 삼을 근거는 남아 있다. 다만 폭16이 가장 좋은 공통 구조라는 근거는 없다.** Taxi에서는 직전 관측 표현을 함께 쓰는 pair MLP가 동등 용량의 현재 표현 대조보다 수량 예측에 유리했다. RAF에서는 작은 폭의 큰수량 RMSE 개선과 다른 구간의 악화가 상쇄되고, Validation에서의 이력 이득이 Test까지 유지되지 않았다. 단순 폭 증가·이력 강화는 우선순위가 낮다.

다음 설계 후보는 **같은 총 용량의 2단 순차 잔차 이력 MLP**다. 이를 지지하는 직접 성능 증거는 아직 없으며, 기존의 병렬 한 단계와 구별되는 검증 질문이다. 자세한 식·대조·중복 감사·반증 조건은 [HYPOTHESIS.md](HYPOTHESIS.md)에 기록했다. 학습은 시작하지 않는다.

## 비교 범위와 당시 구조

- 원본 비교: `reports/titantpp_three_dataset_final_comparison_20261005_v1/comparison_receipt.json` 및 해당 per-seed/aggregated/selected-checkpoint CSV. Taxi와 RAF만 수치 분석했고 외부 모델은 기존 matched-head 6종 저장 결과만 사용했다.
- 선택: 전체 Validation raw수량 RMSE 최초 strict finite 최소 epoch. 같은 checkpoint의 MAE·TimeNLL·tail을 함께 비교했다. Test를 보고 새 epoch나 폭을 선택하지 않았다.
- 이력 MLP는 Titan encoder1과 encoder2 사이에 있으며 attention과 두 종류의 기존 메모리는 남아 있다. standalone MLP나 CNN을 런타임에서 제거한 모델이 아니다.
- 8개 분기는 모두 현재64차원 표현과 **같은 직전 관측64차원 표현**을 받는다. 관측 길이 임계값1/2/4/8/16/32/64/128에 따라 가용 분기가 늘고, 합은 항상8로 나눈다. 각 표현에는 이미 encoder1의 이력이 들어 있다.
- 모든 분기 사용(all-available)은 직전 관측이 있으면 8개 MLP 분기를 모두 쓰는 조건이다. 모든 과거 event를 입력한다는 뜻이 아니다. 현재 표현만(current-only)도 attention 이력을 가진 표현을 쓰므로 모델 전체의 무이력 대조가 아니다.
- 폭4 보정은6,144가중치, 폭8은12,288, 폭12는18,432, 폭16은24,576이다. current-only(64→6→64)와 all-available(128→4→64)은6,144로 **폭4에만** 맞춘 대조다. 폭16 대비로는 용량 차이도 포함한다.
- 현재 working tree의 HistoryWidth 파일은 과거 frozen source와 달랐다. 아래 구조 설명은 원본 registry에 결속된 두 frozen source 파일을 읽고 SHA를 확인한 것이다. 다른 사용자의 현재 코드는 수정하지 않았다.

## Taxi에서 남은 이득

1. **직전 표현을 함께 쓰는 효과는 동등 용량 대조에서 남았다.** 폭4−current-only는 Validation 평균 RMSE−10.337/MAE−3.189, Test−25.551/−6.526이며 두 split의3seed 모두 두 지표가 개선했다. 다만 current-only는 입력 차원과 hidden 폭이 다르므로 직전 관측 정보 하나만의 인과 효과로 분해한 것은 아니다. TimeNLL은 pair MLP가 두 split 모두3seed에서 더 높다.
2. **폭16의 평균 이득과 seed 예외를 구분해야 한다.** 폭16−폭4 Test RMSE는 seed42 −44.530, seed52 +26.054, seed62 +2.783이다. MAE는−10.377/+7.397/−0.503이다. 폭16 평균의 수량 개선이 모든 seed의 안정적 개선을 뜻하지 않는다.
3. **Validation 순위가 Test까지 그대로 이어지지 않았다.** 폭8은 Validation77.735/25.040으로 폭16 77.826/25.178보다 조금 낮지만, Test139.415/41.684로 악화했다. 폭8은 Test3seed 모두 폭16보다 RMSE·MAE가 높았다. 폭12는 반대로 Validation 평균이 나쁘고 Test 평균이 좋다. 폭12의 Test만 보고 기준선을 바꾸지 않는다.
4. **분기 사용 방식도 영향을 줬지만 이미 시도한 축이다.** all-available−폭4 Test RMSE/MAE는3seed 모두 개선하고 평균−19.320/−5.076이다. Validation 평균도 개선하지만 seed별 방향은 섞인다. Test TimeNLL 평균은1.0292→1.1848로 악화했다. 이를 새 gate나 모든 분기 사용의 공통 성공으로 포장하지 않는다.
5. **외부 비교:** 폭16은 Validation RMTPP 대비 RMSE−17.84%/MAE−11.70%, Test S2P2 matched-head 대비−1.86%/−2.16%였다. Test 평균 차이는 작고 seed 변동은 크다. 우월성의 통계적 확증은 아니다.

## RAF에서 부족한 부분

1. **폭16 확대가 수량 성능을 개선하지 못했다.** 폭4−폭16은 Validation RMSE−0.132/MAE−0.013, Test−0.453/−0.093이다. Test는3seed 모두 두 수량 지표가 개선했다. 그러나 Test TimeNLL은 폭16 3.8865에서 폭4 4.0468로 높아졌다.
2. **큰수량 이득과 다른 구간의 손해를 분리해야 한다.** 폭4−폭16 Validation 평균 제곱오차 합계는−60,260.713이다. q>200의50개 대상에서−131,796.398이고 나머지6,640개에서는+71,535.685다. Test도39개 큰수량에서−228,527.996, 나머지5,187개에서+39,072.279다. 작은 폭이 전체 구간을 고르게 고친 것은 아니다.
3. **분기를 더 많이 쓰는 방식은 같은 방향으로 통하지 않았다.** all-available−폭4는 Test RMSE+0.203/MAE+0.194다. RMSE3seed 모두 악화했다. 폭16과 비교해도 Test RMSE는 낮지만 MAE는+0.101로 높다. 큰수량 제곱오차 감소−431,036.123과 나머지 구간 증가+326,469.772가 동시에 생겼다.
4. **current-only의 Test 우위는 Validation에서 재현되지 않았다.** current-only−폭4는 Validation RMSE+0.257/MAE+0.054, Test−0.331/−0.040이다. Test MAE도 seed52는 악화한다. 따라서 RAF는 이력이 필요 없다는 결론이나 Test를 근거로 현재 상태 모델을 채택할 근거가 아니다.
5. **폭16은 외부 최우수의 네 지표 모두를 넘지 못했다.** Validation RMSE는 S2P2보다+0.26%, MAE는 RMTPP보다+1.40%; Test는 각각+1.19%/+2.45%다. 지표별 최우수 모델이 서로 다르다는 점을 유지한다.

## Train 근거와 해석의 한계

폭8/12의 저장 Train 진단은 수량 구간별 고정 표본에 N_bin/n_bin 가중치를 적용한 추정치다. Taxi 표본7,934개가38,393개, RAF는 원본 진단에 기록된 표본이 전체 Train을 대표하도록 가중됐다. 전체 Train 전수와 섞지 않는다. 폭16의 Train 진단은 표본 방식이 달라 같은 대상의 비교로 사용할 수 없다.

- Taxi 폭8/12 대 폭4 Train 수량 개선은 seed42에만 있고52·62는 RMSE·MAE 모두 악화했다. 단순히 넓은 MLP가 Train은 항상 더 잘 맞춘다고 할 수 없다.
- RAF 폭8은 Train RMSE3seed 개선인데 Test RMSE는 폭4보다 평균 악화했다. 폭12는 Train MAE3seed 개선이나 Test MAE 평균은 폭4보다 높다. 저장된 해당 표본에서의 경향이며 폭16의 과적합 증명은 아니다.
- 이번 오류 분해는 전체·tail의 N×RMSE², N×MAE에서 차감한 집계다. 개별 대상의 AE/SE나 예측 전 이력별 사례를 복원한 분석이 아니다. 여기서 말하는 non-tail은 q≤3449(Taxi) 또는 q≤200(RAF)이며 과거 보고서의 별도 body 구간과 다르다.
- 선택된 epoch의 차이도 결과에 포함된다. 예를 들어 Taxi 폭16 seed42/52/62는27/82/94이고 폭4는60/160/85이다. 같은 epoch나 같은 학습량에서 폭 하나만의 인과 효과를 추정한 것이 아니다.
- 과거 캠페인·장치·Runtime 및 단일seed 탐색과3seed 결과를 구분한다. 새 native 재현과 동일 장치 재실행은 하지 않았으며 속도 우위를 주장하지 않는다.
- Validation endpoint 중 일부에는 target/truth digest 자체가 없다. 원본 population SHA와 선택상태·count·source·loader 연결을 재사용했지만 이번에 개별 예측까지 재검증했다고 주장하지 않는다.
- Test는 이미 여러 설계 판단에 참고됐다. 새 독립 평가, p-value, 통계 유의성, 원인 확정을 주장하지 않는다.

## 검증과 남은 순서
