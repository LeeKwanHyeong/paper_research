# Intermittent 자재별 Validation / Test 패턴

**원자료와 비교 범위를 확인한다 — 완료**
- 현재 요청에서 Validation과 Test의 자재별 패턴 열람·그림 작성을 승인받아, 최근 구성요소 대조의 동결 자료를 읽었습니다.
- 사업장–자재별 5,000개 시계열의 Validation 86,285개와 Test 88,019개 기록을 연결했습니다. 원자료와 split은 seed42·52·62가 공유하므로 실제 수량선은 seed별로 달라지지 않습니다.
- 원자료의 시간 단위는 주이며, 모든 기록 날짜는 월요일입니다. 일자축에 주간 양수 수량 기록을 표시했습니다. 무관측 날짜를 일별 0 수요로 채우거나 새로 보간하지 않았습니다.
- 날짜는 기존 사용자 확인 기록에 따라 보안·비식별 목적 이동값입니다. 2030년 등 표시 날짜를 실제 미래 수요라고 해석하지 않습니다. 원래 달력 날짜와 날짜 이동량은 복원하지 않았습니다.

**같은 자재의 두 구간을 연결해 볼 수 있게 만든다 — 완료**
- `index.html`: 모든 자재 검색·선택, 평균 수량 변화 정렬, 기간 확대, 로그축, 현재 그래프 PNG 저장을 제공하는 로컬 HTML입니다. 외부 CDN 없이 Plotly를 포함합니다.
- 파란 선은 Validation, 주황 선은 Test입니다. 각 자재의 첫 Test 기록일에 `Horizon — Test 시작` 세로 점선을 표시합니다. 이는 split 전환점이며 다중 스텝 예측 리드타임이 아닙니다.
- 관측점 사이의 선과 두 구간 사이의 회색 연결 점선은 시각적 가이드입니다. 기록 사이의 실제 수량이나 예측을 생성한 것이 아닙니다.
- 같은 자재는 하나의 y축을 사용합니다. 다른 자재 간에는 개별 y축을 사용하므로 절대 크기를 비교할 때 눈금도 확인해야 합니다.
- 원자료만으로 특정 자재가 성능 역전의 원인이라고 확정할 수 없습니다.

**비교 미리보기와 원본 검증을 남긴다 — 완료**
- `patterns_overview.png` / `patterns_overview.pdf`: 수량 평균 감소 2개·증가 2개·평균 변화가 작은 2개의 사후 관측 예시입니다. 모델 오차로 선정한 자재가 아니며, 두 seed의 모델 역전을 대표한다고 주장하지 않습니다.
- 입력 SHA, 저장된 평가 영수증16개 SHA, 174,304개 기록 수, 5,000개 자재 모두 두 split 존재, 중복 자재·날짜0, 자재별 Validation 마지막일 < Test 첫날을 확인했습니다.
- 정적 PNG는 직접 시각 확인했습니다. HTML JavaScript는 구문 검사를 통과했습니다.
- 앱 내 브라우저에서 로컬 `file:` HTML 열기는 보안 정책으로 차단됐습니다. 우회하지 않았으며 브라우저에서 검색·확대·내보내기 동작을 실제로 검증하지 못했습니다. HTML은 사용자가 일반 브라우저에서 직접 열어 볼 수 있습니다.
- 새 학습·추론·원격 호출·checkpoint 재선택은0이며, 기존 자료·평가 원본·원고·자동화는 변경하지 않았습니다.

**세 seed의 예측선과 실제 수량을 겹쳐 비교한다 — 다음 작업**
- 최신 구성요소 Test 평가의 저장 결과는 seed42·52 NONE/CNN/GRU/FULL 8개입니다. seed62를 임의로 포함하지 않았습니다.
- 이 결과들은 `raw_predictions_written=false`로 날짜별 예측 행이 없습니다. HTML 아래의 seed별 RMSE·MAE 표는 검증한 저장 집계이고, 위 곡선은 실제 수량입니다.
- 예측선을 추가하려면 동일 선택 checkpoint·동일 split의 원본 예측 행과 자재·목표 날짜 연결이 필요합니다. 예측을 새로 내보내는 작업은 원 Runtime·입력·선택 고정 계약에 따라 진행해야 하며, 현재 그래프 작성에 포함하지 않았습니다.
- 다른 과거 캠페인의 3seed 예측을 최근 구성요소 대조의 곡선으로 섞어 쓰지 않습니다.

## 파일

- `index.html`: 자재 선택 그래프
- `patterns_overview.png`, `patterns_overview.pdf`: 비교 미리보기
- `series_profiles.csv`: 전 자재의 두 구간 기록 수·기간·수량 요약
- `observed_validation_test.parquet`: 그래프에 사용한 원자료 필드
- `chart_data.json`: HTML에 결속된 동일 관측 데이터와 검증한 집계
- `QA.json`, `output_manifest.json`: 입력/출력 SHA와 검증 범위
- `build_patterns.py`: 표준 Plotly/Matplotlib로 동일 그림을 만드는 로컬 도구

원자료: `search_artifacts/titantpp_components_inter8_test_20261014_v1/data/intermittent_frozen_5000_with_split.parquet`.

수량은 일평균이 아니라 양수 기록당 수량입니다. Test 패턴을 본 뒤 모델이나 선택 checkpoint를 바꾸는 작업은 수행하지 않았습니다.
