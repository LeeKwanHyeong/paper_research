# 저장 결과 비교 독립 검토

상태: **PASS_independent_stored_comparison**. 차단할 발견과 계산 불일치가 없습니다.

원 집계 도구를 실행하거나 가져오지 않고, CSV의 seed별 값에서 Decimal 60자리 연산으로 산술평균과 표본분산 제곱근을 계산했습니다. 84개 요약의 RMSE·MAE 평균/표본SD, 지표별 최저 36행, Validation 선택 모델 18행, 원본 MLP−외부 평균 차이 12행과 seed 차이 36행을 검산했습니다. 총 2846건 점검에서 불일치0이며 부동소수점 표현과 Decimal 계산의 최대 절대 차이는 5e−14입니다.

보조 참조 18행은 SHA가 결속된 부모 집계 CSV와 모든 원래 필드를 대조했고, 보고서의 36개 RMSE·MAE 표기도 확인했습니다. 이 보조표의 개별 seed 원본을 별도로 재집계한 검토는 아닙니다. Intermittent Validation의 Deep Renewal 및 마지막값 MAE, RAF Test 이력평균 RMSE 반례가 본문에 유지됩니다.

Cap과 원본은 정답·입력이 다른 과제로 분리됐고, 두 과제 사이의 점수 차이나 개선율은 계산하지 않았습니다. 동일 Cap 외부 결과는 N/A입니다. 원본 MLP 최저는 네 구조 안의 최저, 외부 최저는 공통 head를 맞춘 여섯 모델 안의 최저이며 모든 과거 모델이나 논문 원형 전체를 뜻하지 않습니다. 다른 head와 결정적 기준선은 별도 보조표입니다.

Validation으로 고른 같은 구조의 Test와 지표별 Test 사후 최저가 구별됩니다. 서로 다른 최저 구조를 하나의 모델로 합치지 않았고, 독립 일반화·통계적 유의성을 주장하지 않습니다. 대상 수의 일치만으로 truth 동일성을 증명하지 않는다는 점, 부모 증적의 대상 결속 범위와 Runtime 차이도 공개돼 있습니다.

이번 검토는 입력 CSV·부모 집계/증적 및 보고서의 계산·해석 검토입니다. 모든 상위 checkpoint binary와 개별 예측을 다시 읽거나 재추론한 검토가 아닙니다. 새 학습·추론·원격 호출·기존 봉인 보고서 수정은 없습니다. 검토 파일의 SHA는 QA.json에 기록했습니다.

검토 완료 뒤 이 QA 두 파일은 부모 승인 없이 수정하지 않습니다. 검토 대상의 수치·선택·문구가 바뀌면 해당 변경을 다시 검토해야 합니다.
