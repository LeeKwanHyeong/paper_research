# CNN·GRU Test 최종 비교와 후속 Contribution 판단

2026-10-05. **신규9조건의 학습·원본 SHA 회수·Validation 재현·Test 평가·결과 비교 — 완료.** Taxi·Intermittent·RAF를 대상으로 기존 모델까지19개 모델 ID를 연결했다. 신규 모델은 seed42 하나이며, 기존3seed 결과는 별도 참고표다. Instacart는 후속으로 유지한다.

**후속 구조 후보로는 GRU54를 우선 검증할 것을 권고한다.** Intermittent의 MAE와 RAF의 학습 모델 RMSE에 장점이 있으나 Taxi에서 크게 악화된다. 따라서 기존 MLP16 비교 기준선은 유지하며 GRU54를 세 데이터 공통 최종 모델로 채택하지 않는다. 모든 가용 분기 MLP와 단순 수량 기준선도 필수 대조로 유지한다. 현재 증거만으로 신규 구조의 보편적 우월성이나 논문 기여가 확정된 것은 아니다.

공통 출력부 외부 비교군 중 전체 RMSE 최선은 세 데이터 모두 S2P2다. Taxi CNN+GRU54는 S2P2보다11.95% 낮지만 큰 수량 RMSE는589.041 대525.614로 나쁘고, 시간 NLL도1.275330 대0.701194로 나쁘다. 기존 MLP16보다 전체·큰 수량 RMSE/MAE와 전체 시간 NLL이 모두 나쁘다.

Intermittent GRU54는 S2P2보다 전체 RMSE8.56%, MAE17.52%, 큰 수량 RMSE17.31% 낮다. 그러나 모든 가용 분기 MLP의 전체/큰 수량 RMSE2.547916/9.049803과 전체 시간 NLL9.313896에는 미치지 못한다. GRU54의 대응 값은2.650716/13.533961/16.730821이다. 시간 지표에서는 THP7.588317이 더 낮다.

RAF GRU54와 S2P2의 전체 RMSE 차이는39.603708 대39.637374로 **0.085%**에 불과하다. GRU54는 MAE가 낮지만 큰 수량 RMSE402.369382는 S2P2의399.636057보다 높고, 전체 시간 NLL3.690585도 S2P2의3.648862보다 높다. 수량 전용 이력 평균은 큰 수량 RMSE368.665548로도 더 낮다. 작은 단일seed 차이를 안정적 성능 우월성으로 해석할 수 없다.

**수량·큰 수량·시간을 모두 이기는 하나의 모델은 확인되지 않았다.** 데이터 사이의 raw RMSE를 더하거나 임의 가중 점수로 승자를 만들지 않았다.

## 3. Validation에서 좋아 보였던 결과가 Test에서는 유지되지 않았다

Taxi CNN+MLP16의 Validation RMSE는76.487600으로 MLP16의82.499162보다 낮았지만 Test에서는128.389326 대95.931543으로 방향이 뒤집혔다. CNN+GRU54도 같은 방향 반전이 있었다. 이는 **관측된 일반화 차이**이며 과적합·분포 변화·시간 손실 영향 중 특정 원인을 확정한 진단은 아니다.

신규 후보 내부에서는 CNN+MLP16이 세 데이터 모두 Validation RMSE 최저였다. Test에서는 Taxi가 CNN+GRU54, Intermittent·RAF가 GRU54였다. Test를 보고 checkpoint를 바꾸지는 않았다. 이 결과는 Validation 선택의 실제 Test 성능으로 보존한다.

기존3seed 참고에서도 모델 순위가 seed42와 같다고 가정할 수 없다. 예를 들어 Taxi의 모든 가용 분기 MLP Test RMSE는99.304085±12.846499, MLP16은113.392687±16.501995다. 신규 단일seed 값을 이 평균들과 같은 확정 결과로 비교하지 않는다. [기존3seed 평균·표본 표준편차](BASELINE_THREE_SEED_REFERENCE.md)

[2×2 구조 대조](FACTORIAL_CONTRASTS.md)36개를 계산했다. Taxi Test RMSE의 interaction이 음수여도 결합 모델 자체가 MLP16을 이기지는 않는다. Intermittent·RAF Test 전체 RMSE interaction은 각각+0.519230, +0.675982로 산술 가산 기준보다 결합 오차가 높다. RMSE의 비선형성·단일seed·전체 구조 변경을 고려해 이 값을 확정 synergy나 독립 인과효과로 부르지 않는다.

GRU 교체는 순환 연산뿐 아니라 참조 범위·활성 조건·잔차 크기·비선형성도 바꾼다. MLP16 보정24576개와 GRU54 보정24732개는 근접 예산일 뿐이다. CNN은576개를 더한다. 신규 전체 파라미터 수는 Taxi/Intermittent에서 CNN+MLP16 115011, GRU54 114591, CNN+GRU54 115167이며 RAF에서는104003/103583/104159다. 계산량·속도가 같다는 의미는 아니다.

CNN+GRU 결합과 Q/K/V convolution 자체는 선행 사례가 있어 최초 구조라는 주장을 할 수 없다. 검증할 기여는 **가용한 관측 사건 문맥을 제한된 잔차 보정으로 활용할 때 수량·큰 수량·시간의 상충이 어떻게 달라지는가**다. 신규 모듈의 causal/reset 처리, 참조 범위와 잔차 크기를 맞춘 대조, seed별 방향 재현이 그 근거가 되어야 한다. [원본 문헌·구조 검토](CONTRIBUTION_EVIDENCE.md)

## 5. 완료 증거와 해석 경계

- A1007조건과 RTX 재개2조건의 terminal·원본 회수를 확인했다. RTX 원본26개를 SHA로 검증했다. A100 Pod 삭제·목록 부재와 보수비용 약$25.82는 기존 증거를 연결했다. 비용 추정은 청구서가 아니다.
- 5080의 새 전용 평가 폴더에서 Validation9 gate를 모두 통과한 뒤 Test9를 실행했다. 소스117개·데이터·선택 epoch·state SHA를 유지했다. 원본 선택10/12epoch를 포함한 RTX 재개 조건도 재선택하지 않았다.
- 첫 평가 시 NVRTC 시작 환경 오류가 있었고 Test 접근0·완료0으로 종료했다. 증거를 보존하고 기존 라이브러리 경로를 Python 시작 전에 전달한 별도 attempt2만 수동 실행했다. 공용 Runtime 패키지와 학습 소스는 변경하지 않았다.

## 7. 남은 작업 순서

**GRU54 대조 계약을 구체화한다 — 다음 작업 / 최우선**
- 대상은 paper_research의 Taxi·Intermittent·RAF다. MLP16과 모든 가용 분기 MLP를 유지하고 GRU의 참조 범위·활성 조건·잔차 크기를 맞춘 대조를 먼저 정한다.
- 완료 조건은 순환 보정과 문맥 변경을 구분하고 전체·큰 수량·시간의 개선/손해 기준을 사전에 고정한 상태다. 기존 checkpoint와 Test 선택은 바꾸지 않는다.

**GRU54의 seed별 안정성을 검증한다 — 다음 작업 / 계약 이후**
- 동일3seed 대조로 Intermittent·RAF의 장점과 Taxi 손해가 재현되는지 확인한다. 서버별 독립 조건은 병렬 배치할 수 있지만 신규 GPU 학습은 이번 작업에서 시작하지 않았다.
- 완료 조건은 실패·불리한 값까지 포함한 paired 결과와 변동을 확보한 상태다. 새로운 seed만으로 이미 노출된 Test가 독립 평가로 바뀌지는 않는다.

**논문 최종 평가와 원본 감사를 분리해 마무리한다 — 다음 작업 / 후보 동결 이후**
- 개발 과정에 노출되지 않은 별도 최종 평가 계약을 정하고, CPU binary 재추론 감사와 동일 장비 효율 측정은 별도 수행한다. 감사 작업은 후보 설계와 독립적으로 진행할 수 있다.
- 완료 조건은 제한된 기여 문장과 실험 증거가 일치하는 상태다. 이 보고서 작성으로 전체 연구 감사 완료를 주장하지 않는다.
