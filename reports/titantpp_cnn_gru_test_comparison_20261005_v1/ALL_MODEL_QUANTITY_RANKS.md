# 모든 모델의 수량 지표 순위

학습 모델은 동일 seed42, 결정론 수량 기준선은 seed가 없다. 공통 사건 모집단에서 전체·큰 수량 RMSE와 MAE를 비교한다. 수량 전용 기준선과 native NB를 포함한 관측 순위이며 시간 예측까지 포함한 종합 우월성 순위가 아니다.

각 표는 해당 범위의 RMSE 오름차순이다. MAE 순위는 별도 열이다. 숫자가 작은 RMSE/MAE가 좋다. 시간 NLL은 출력부를 구분한 [주 비교표](TEST_SEED42.md)에서 확인한다.
