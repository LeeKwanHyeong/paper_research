# 활성 분기별 매개변수 수를 맞춘 공유 MLP 대조 검토

작성일: 2026-10-19 · 상태: **보완 설계 검토 완료 / 최종 계약 반영 권고**

기존 `DESIGN_QA.md`는 최초 균일 폭 대조 검토 기록으로 보존한다. 이 문서는 실제로 활성화 가능한 분기 수까지 매개변수 예산을 맞추는 대안을 추가 검토하며, **최종 권고는 공유 폭15 대 독립 폭 `[15,5,5,5,5,5,5,5]`로 갱신한다.** 이 검토에서는 구현·학습·실제 데이터 평가·checkpoint loading·SSH·배포·Test 열람을 수행하지 않았다.

검토 역할은 Architecture Specialist / architecture-reviewer다. 프로젝트 설정에서 확인한 역할 모델은 `gpt-6-astra`, reasoning `high`이며 실제 런타임 모델 식별자는 별도로 조회하지 않았다.

## 추가로 발견한 설계 문제

균일 폭12/5 대조는 등록된 전체 보정 가중치 7,680개를 정확히 맞춘다. 그러나 앞에서 k개 분기만 사용 가능한 조건에서는 공유군과 독립군의 계산 경로에 참여 가능한 가중치 수가 다르다. k=7이면 공유군 6,912개, 독립군 6,720개다. 따라서 데이터가 마지막 문턱에 도달하지 못하면 전체 등록 수 일치가 해당 데이터에서 사용 가능한 가중치 수 일치를 보장하지 않는다.

부모 세션은 RAF의 `max_seq_len=84` 때문에 문턱128인 마지막 분기가 사용되지 않는다고 보고했다. 이번 보완 검토는 이 값을 전달받은 전제로 사용하며 원본 데이터 계약을 독립적으로 다시 확인하지 않았다. 코드에서 확인한 `local_count > threshold` 규칙상 문턱128을 켜려면 최소129개 유효 연속 관측이 필요하므로, 해당 길이 상한이 맞다면 마지막 분기는 활성화되지 않는다.

## 수식 검증

hidden dimension을 d=64, pair 입력을 2d, 공유 폭을 r, 활성 분기 수를 k라 둔다. 기존 문턱은 단조 증가하므로 활성 분기는 항상 앞에서부터 연속이다. padding과 withheld reset도 이 성질을 바꾸지 않는다.

```text
공유 폭 r, k≥1:
P_shared(k) = 2dr + kdr = dr(k+2)

독립 폭 [r, r/3, r/3, r/3, r/3, r/3, r/3, r/3], k≥1:
P_independent(k) = 3d · [r + (k−1)r/3] = dr(k+2)

k=0: 두 군 모두 활성 보정 경로 가중치 수 0
정수 조건: r은 양의 3의 배수
```

첫 독립 분기는 공유 입력 변환과 첫 출력 변환을 합친 비용에 대응한다. 이후 독립 분기 하나의 입력·출력 비용은 공유군의 출력 분기 하나 비용과 같다. 모든 가중치는 실제 계산 경로에 속하며 dummy를 넣을 필요가 없다.

r=15이면 다음 표처럼 모든 활성 분기 수에서 정확히 일치한다. 여기서 개수는 해당 mask에서 수식상 참여 가능한 가중치 수다. 초기 출력0 때문에 순간 gradient가0인 경우나 특정 샘플에서 일부 값이0인 경우를 제외한 실측 자유도라는 뜻은 아니다.

| 활성 분기 수 k | 공유15 | 독립 [15,5×7] |
|---|---:|---:|
| 0 | 0 | 0 |
| 1 | 2,880 | 2,880 |
| 2 | 3,840 | 3,840 |
| 3 | 4,800 | 4,800 |
| 4 | 5,760 | 5,760 |
| 5 | 6,720 | 6,720 |
| 6 | 7,680 | 7,680 |
| 7 | 8,640 | 8,640 |
| 8 | 9,600 | 9,600 |

## 대안과 최종 권고

| 대안 | 얻는 통제 | 남는 한계·비용 | 판단 |
|---|---|---|---|
| 공유12 대 균일 독립5 | 전체 등록 가중치 수 7,680 일치 | k<8의 활성 경로 가중치 수 불일치. 균일 폭 구현은 간단 | 최초 설계로 타당하지만 더 강한 대조가 가능 |
| 공유12 대 독립 [12,4×7] | 전체 7,680 및 모든 k의 가중치 수 일치 | 첫 분기와 나머지 분기의 폭이 달라짐. 공유 폭은12 | 낮은 예산을 고정하려면 타당한 대안 |
| 공유15 대 독립 [15,5×7] | 전체 9,600 및 모든 k의 가중치 수 일치 | 불균일 폭 지원과 식별자·테스트가 필요. 계산량이 12안보다 커짐 | 이번 최종 권고 |

공유 폭을16 이하로 두고 가장 가까운 폭을 선택한다는 사전 기준에서는, 양의 3의 배수 중15가 선택된다. 이 기준을 SCIENCE_SPEC에 먼저 고정한다. 성능을 근거로15가12보다 좋다고 판단한 것이 아니다. 예산을 반드시7,680으로 유지해야 한다는 별도 제약이 생기면12/[12,4×7]이 맞다. 현재 전달받은 범위에는 그런 고정 예산 제약이 없다.

구현 비용은 독립 분기의 폭 목록을 지원하는 작은 변경과 검증 추가다. 모든 데이터셋에 같은 폭 목록을 쓰므로 데이터셋별 구조 선택이나 gate는 추가되지 않는다. 운영 비용과 속도는 실제 구현에 따라 달라지며 아직 측정하지 않았다. 팀이 유지할 계약에는 공유 폭과8개 독립 폭을 명시해야 하며, scalar width만으로 구조를 식별하던 코드를 재사용할 때 주의해야 한다. 향후 변경 비용은 이 폭 목록과 identity를 한곳에서 관리하면 제한적이다.

## 해석에 남는 차이

동일 매개변수 수 대조를 더 엄격하게 만들었지만, 공유만의 순수 인과효과를 식별하지는 않는다. 독립 대조군의 첫 분기 폭15와 나머지 폭5라는 배분 자체가 구조 선택이다. 공유군의 단일 W와 독립군의 분기별 W는 데이터 노출과 gradient 합산 방식이 다르다.

고정된 availability mask 아래 pair 입력에 대한 보정항 Jacobian rank 상한은 공유군15, 독립군 min(64, 15+5(k−1))이다. k=1에서 두 군은 모두 width15 MLP 형태이고, k≥2에서는 함수 공간과 표현 폭이 다르다. 이는 실제 rank 측정이나 전체 모델의 rank 상한이 아니다. 초기 출력0을 유지하므로 처음 W gradient가0인 현상도 정상이다.

권장 주장 범위는 **“동일 전체 매개변수 수 및 모든 활성 분기 수에서 동일한 경로별 가중치 예산을 가진 두 구조의 비교”**다. 동일 표현 용량, 동일 최적화, 동일 실측 연산량, 공유만의 효과로 확대하지 않는다.

## 계약·로컬 검증에 반영할 조건

1. 공유15와 독립 `[15,5,5,5,5,5,5,5]`를 세 데이터셋에 동일 적용한다. 전체 보정9,600개와 full-model trainable parameter count 일치를 확인한다.
2. k=0…8의 prefix별 매개변수 수를 실제 등록된 tensor shape로 계산해 위 수식과 비교한다. 마지막 분기 노출이 없는 데이터에서도 양군의 사용 가능 예산이 맞는지 계약에서 확인한다.
3. 기존 검토서의 공통 입력/log1p·logMSE·time alpha0·head·memory·문턱·/8·mask/reset·RNG·zero output·target withholding 조건을 그대로 적용한다.
4. independent width list, shared input 여부, 총 가중치 수를 metadata와 identity에 포함한다. 기존 균일 폭 arm과 혼동하거나 relabel하지 않는다.
5. synthetic129개 이상 유효 연속 관측으로 모든 분기의 forward와 gradient 경로를 검증한다. 초기 B=0 검증과 nonzero B를 이용한 W 경로 검증을 분리한다. k=1의 두 수식이 대응 가중치를 사용하면 일치하는지도 확인한다.
6. 현재 검토는 원격 실행이나 새 학습을 승인하지 않는다. 5090/5080의 현재 작업과 기존 산출물을 보존한다.
