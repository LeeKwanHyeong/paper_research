## 해석과 제한

- 같은 Cap 데이터의 Validation 비교이며 RAF cap10, Intermittent20, Taxi65다. Test와 원본 비Cap 수치를 읽거나 혼합하지 않았다.
- 기존 MLP16은 시간 가중치0의 검증된 저장 기준선이다. 공유형도 시간 가중치0이나 완료 학습의 선택 checkpoint 기록이며 최종 캠페인 Validation18·원본 회수는 아직 미완료다.
- 외부 모델은 공통 수량·시간 head를 적용한 구현이며 log 수량 손실과 시간 손실(가중치1)로 학습했다. 현재 MLP16·공유형과 동일 목적함수의 순수 백본 대조가 아니다.
- 외부 RAF9는 2026-10-18 10:07:31 KST 저장 학습 완료 관측으로 최종 캠페인 Validation gate·회수 미완료다. Taxi RMTPP는 2seed만 완료해 3seed 평균을 산출하지 않았고 나머지 외부 대상은 미완료다.
- 외부 비교군은 사용자의 이전 실험 중단 요청 상태이며 이번 정리에서 재시작·추론·SSH를 수행하지 않았다.
- 공유형은 전부5080/cuDNN91900, RAF 기존MLP16/외부는5090/cuDNN92000, Inter 기존MLP16의42는5080/52·62는5090다. 런타임 차이가 있다.
- 선택은 최초 strict finite fullValidation raw quantity RMSE 최소 epoch이며 MAE는 같은 epoch에서 가져왔다. 평균±표본SD(ddof1), seed42·52·62이며 데이터셋 간 raw 오류를 평균내지 않는다.

RAF에서 공유형은 기존 MLP16보다 두 평균 오류가 소폭 낮지만, 외부 RMTPP의 RMSE 및 S2P2의 MAE보다 높다. Taxi는 공유형 MAE가 낮아졌으나 RMSE는 seed52·62에서 악화했다. Intermittent는 공유형 평균 RMSE·MAE 모두 악화했다. 세 데이터셋 공통 개선 또는 외부 대비 우위를 주장할 근거는 없다.
