# 공유형 이력 MLP 준비 결과

**계약·구현·로컬 검증 — 완료**

- 공유형15는 현재·직전 관측의 관계를 하나의 비선형 변환으로 학습하고8개 출력 분기에서 재사용한다. 독립 대조군은 분기별 폭 `[15,5,5,5,5,5,5,5]`를 사용한다. 보정부는 각각9,600개 가중치이며 각 활성 분기 수에서도 수식에 관여하는 가중치 수가 같다. 두 구조의 함수 공간이나 최적화가 같다는 뜻은 아니다.
- Cap Taxi65·RAF10·Intermittent20, 시간·수량 log1p, log-MSE, 시간 가중치0, 공통 head·memory·예산·checkpoint 선택 기준을 유지했다. 기존 MLP16의 Validation9개는 저장 결과만 재사용한다.
- 최종 검사72개·하위 사례106개가 통과했다. 실제 학습 엔진을 두 후보의 작은 CPU 합성 데이터에 연결해 checkpoint 선택·저장·엄격 재로딩·동일 대상의 개별 예측과 여섯 지표 재현을 확인했다.
- 기존 소스·입력·기준선과 연결된990개 파일은 검사 전후 SHA가 같았다. 준비 계약은 기존 소스963개와 새 소스3개, 입력6개, 기준선9개에 결속했고 로컬 prepare/verify가 모두 exit0이다.
- 합성 CLI 출력 오류는 새 도구의 출력 부분만 수정했다. 최초 원문과 합성 산출물은 보존했고 최종 실제 CLI 확인까지 통과했다.

**실제 성능·서버 검증 — 미실행**

실제 Cap 학습·추론0, SSH0, native GPU 검증0, Test0이다. 현재5080/5090 학습·복구 절차와 기존 CNN·checkpoint·결과는 변경하지 않았다. 시간 head는 학습하지 않으므로 TimeNLL은 진단값이다. 준비 결과는 개선 효과의 증거가 아니다.
