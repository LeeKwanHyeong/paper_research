# 현재 V 차분 CNN 선택계수의 응답 감사

현재 선택 epoch는 seed42=9, seed52=5, seed62=22로 고정했다. 모델을 만들거나 예측을 계산하지 않고 state tensor만 읽었다.

| seed | a 평균 | b 평균 | 관측3 이상 Nyquist 평균 [최소, 최대] | 관측2 Nyquist 평균 [최소, 최대] | DC(관측1/2/3+) |
|---|---:|---:|---|---|---|
| 42 | -0.186978 | 0.079488 | 0.467067 [0.072718, 1.460454] | 0.626043 [0.234489, 1.194034] | 1 / 1 / 1 |
| 52 | -0.153019 | 0.079906 | 0.534149 [0.159738, 1.170861] | 0.693962 [0.441166, 1.117062] | 1 / 1 / 1 |
| 62 | -0.187058 | 0.030677 | 0.564530 [-0.658018, 1.697077] | 0.625884 [-0.422480, 1.519162] | 1 / 1 / 1 |

여기서 Nyquist는 관측 순번에 따른 교대 입력 [1, −1, 1]의 부호를 포함한 응답이다. 실제 시간 간격이나 실수량의 변화를 뜻하지 않는다. 관측2의 값은 짧은 이력 경계에서 계수 다항식을 계산한 값이며, 전체 모델의 정상상태 주파수 응답이 아니다.

`h3=[1+a,b−a,−b]`, `h2=[1+a,−a]`, `h1=[1]`이므로 상수 잠재 V의 DC는 모두1이다. 기존 CNN의 저장된 V DC 평균은 seed42/52/62에서 각각 1.100876, 1.124947, 1.143706였다. 기존 CNN checkpoint는 다시 읽지 않았다.

각 채널의 a·b와 세 경계의 전체 계수·DC·Nyquist, 부호 없는 응답 크기 및 기술통계는 RESULT.json에 기록했다. 채널별 표현의 좌표가 서로 다른 학습 모델 사이에서 맞춰져 있지 않으므로 계수 변화만으로 출력 효과를 직접 비교할 수 없다.

필터 계수의 gain은 raw 수량 오류, 실제 활성값으로 가중한 효과, 또는 실패 원인이 아니다. 상수 잠재 V 보존도 최종 수량 편향 제거를 보장하지 않는다. 임의 gain 문턱이나 새 학습 진입 기준을 정하지 않았다. 다음 후보 선정에는 별도의 분기 기전 진단이 필요하다.

원본 binary·선택 metadata/history·계약 및 기존 CNN 요약의 SHA를 처리 전후 확인했고 모두 같았다. 학습·모델 생성·forward·원격·Test 접근은0이다. 로컬 torch는 2.14.0, 학습 Runtime은 후보5090/cuDNN92000과 기존CNN5080/cuDNN91900으로 다르다.

고정 수학 합성 검사 79개 통과. 전체 이름·dtype·shape·bytes를 포함한 state SHA와 개별 계수 raw SHA, checkpoint 파일 SHA는 서로 다른 hash domain으로 기록했다.
