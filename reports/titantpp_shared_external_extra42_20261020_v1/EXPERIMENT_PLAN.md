# 공유형·외부 비교군 추가 2seed 실행

**현재 기준선을 보존한다 — 완료**
- 원본 RAF·Taxi·Intermittent의 기존42·52·62 결과와 선택 checkpoint를 재사용한다. 기존 CNN·MLP16은 재학습하지 않는다. 5090 원본9 학습과 종료 후 회수 프로세스는 유지한다.

**5080에서 추가72·82를 검증하고 시작한다 — 진행 중**
- 공유형과 외부6종, 세 데이터셋의42개를 신규 경로에 배치한다. 공통 입력·손실·head와 각 비교군 구조를 기존과 맞춘다.
- 기존 중단 작업을 보존하고 실제3동시 합성검증을 통과해야 시작한다. 학습·평가 모두 최대3개이며 기존 기한은 연장하지 않는다.

**Validation 선택 모델의 Test를 산출한다 — 다음 작업**
- 전체42 학습 종료와 선택 checkpoint SHA를 확인한 다음 Validation42 재현을 모두 통과해야 Test42에 들어간다. 기존3seed 결과를 수정하지 않고 추가2seed와 별도로 기록한다.

**Intermittent 최종 선택이 고정본과 같은지 확인하고 논문을 시작한다 — 외부 작업 대기**
- 5090 종료·회수·Validation 재검증 뒤 epoch5·5·11과 canonical model tensor SHA를 고정본과 대조한다. 직렬화 binary SHA 차이를 모델 차이로 해석하지 않는다.
- 모두 같으면 새 원고 경로에서 작성한다. 추가2seed는 계속 진행하며 불리한 결과와 반복 Test 참고의 한계를 함께 남긴다.
