# RAF에서 공유형의 이득이 제한되는 이유

상태: 저장 Train·Validation 자료 분석 완료. 새 학습·모델 추론·checkpoint 로드·Test 성능 열람·SSH는0이다. 기존 학습과 자동 회수, checkpoint·결과·실패는 변경하지 않았다.

## 무엇을 비교했는가

- 현재 Shared15 seed42·52·62의 동일한6,690개 Validation 예측과 외부6종의 같은 대상 예측을 연결했다. 외부6종의 Train은 각각25,779개 대상도 보존돼 있다. 총39cohort의 수치를 원 receipt와 재계산해 확인했다.
- 현재 공유형의 Train 개별 예측은 없다. `training_validation_predictions.jsonl.gz`도 실제로는 Validation 예측이다. Shared의 Train–Validation raw오류 차이로 과적합을 판정할 수 없다.
- 별도5seed Validation 집계는 이전 보고서로 유지한다. 이번 개별행 진단은 회수가 끝난3seed만 사용한다. 추가72·82는 저장된 Validation epoch 이력의 선택 상충을 살펴볼 때만 썼다.
- 아래 RMSE·MAE는 seed별 지표의 산술평균이다. SSE 비중은 seed별 비중의 평균이다. 차이의 가산 분해는 RMSE 자체가 아니라 MSE와MAE에 적용했다.

## 1. 공통 난점: 아주 적은 큰 수량이 RMSE를 좌우한다

RAF Validation에서 q>200은50/6,690행,0.747%다. 현재 공유형의 제곱오차 합(SSE)에서는68.638%를 차지한다. 반면 동일 행의 log1p 수량 제곱오차 합에서는4.851%다. 이는 같은 예측에서도 큰 수량이 두 평가·손실 척도에서 차지하는 비중이 다르다는 관측이다. 이것만으로 log1p 입력이 잘못됐거나 손실 변경이 개선을 보장한다고 결론낼 수 없다.

큰 수량50개의 실제 수량 평균은368.66인데, 공유형의 예측 평균은89.45다. RMTPP75.27, S2P2 90.94로 세 모델 모두 크게 과소예측한다. 공유형만의 문제가 아니다. 공유형 SSE의35.43%가 상위5개 부품,75.52%가 상위50개 부품에 집중된다(Validation에는4,121개 부품).

| Validation 수량 구간 | 대상 수 | 공유형 RMSE / MAE | RMTPP RMSE / MAE | S2P2 RMSE / MAE |
|---|---:|---:|---:|---:|
| q≤200 | 6,640 | 19.094 / 7.214 | 18.372 / 6.996 | 19.292 / 7.252 |
| q>200 | 50 | 325.510 / 279.210 | 338.945 / 293.393 | 324.312 / 277.715 |

따라서 RMTPP에 대한 공유형의 RMSE 이득은 큰 수량에서 발생한다. 큰 수량을 제외한6,640행에서는 오히려 RMTPP가 두 지표 모두 낮다. S2P2와는 큰 수량에서도 유사한 수준이라 전체RMSE 우세가 작다.

## 2. 상대적 MAE 약점: 큰 관측 뒤 급락할 때 높은 예측이 남는다

현재 수량이 직전 관측 수량의1/5 이하인 행은577개,8.625%다. 이 사후 진단 구간은 예측 입력이나 학습 gate로 사용하지 않았다.

| 동일 Validation 구간 | 공유형 MAE | RMTPP MAE | 전체 MAE 차이에 대한 기여 |
|---|---:|---:|---:|
| 직전 수량의1/5 이하로 급락 | 16.646806 | 14.542938 | +0.181455 |
| 나머지 행 | — | — | −0.070875 |
| 전체 | 9.246784 | 9.136205 | +0.110580 |

이 급락 구간에서의 공유형 상대 손해는3seed 모두 양수다. seed62가 전체MAE에서 RMTPP보다 조금 좋더라도, 급락 구간에서는 더 나쁘다. 전체 손해보다 이 구간의 기여가 크고 다른 구간이 일부 상쇄한다.

수량 구간으로 따로 분해하면 q≤200의 전체MAE 차이 기여는+0.216586, q>200은−0.106007이다. 이 분해와 급락 분해는 서로 겹치는 다른 분할이므로 두 기여를 합치지 않는다.

사후 예시: RAF::02390의 직전 관측은1,830, 다음 실제 수량은100이다. 공유형3seed 예측은295.75~327.02, RMTPP는176.93~200.45다. 이 예시는 미리 정한 급락 구간에서 MAE 차이가 큰 사례를 고른 것으로, 독립 검증 사례나 전체 현상의 인과 증명은 아니다.

행동으로 기술하면 공유형은 RMTPP보다 큰 수량의 과소예측을 완화하는 대신, 급락 뒤에도 높은 수준을 유지하는 경우가 있다. 내부 표현에서 직전 수량을 과도하게 기억한다는 기전까지 입증한 것은 아니다.

## 3. 구조와 데이터의 구체적 불일치 후보: 이력 길이별 분기 사용이 바뀐다

RAF는5,000개 부품의 월별 양수 수요 이벤트다. 무수요 월은 이벤트에서 제외하지만 월 단위 공백은 delta_t에 보존한다. 무수요 월을 누락값으로 취급한 것은 아니다.

| 항목 | Train | Validation |
|---|---:|---:|
| 다음 이벤트 예측 대상 수 | 25,779 | 6,690 |
| 관측 이력 중앙값 / 최대 | 3 / 14 | 7 / 16 |
| 관측 이력이8개 이하인 비중 | 96.86% | 74.74% |
| 마지막 관측 위치에서 활성 분기 평균 | 1.763 | 3.032 |
| lag8 기준 분기 활성 비중(history_length>8) | 3.138%(809행) | 25.262%(1,690행) |

공유형은[1,2,4,8,16,32,64,128]문턱을 사용한다. 뒤쪽4개 문턱16·32·64·128은 Train/Validation에서 한 번도 활성화되지 않는다. 네 번째인 lag8 분기를 쓰는 비중은 Validation에서 약8.05배다. 같은 현재·직전 관계 특징을 공유하더라도 학습 때 드물던 출력분기 조합을 Validation에서 더 자주 사용한다.

실제오류도 점검했다. Shared−S2P2의 MSE 차이에서 이력9개 이상 구간은+17.295709를 기여하고, 나머지 이력 구간은−19.159348로 상쇄한다. 이력9개 이상에서 수량60~200의61행과200초과23행의 손해가 두드러진다. 이력 길이와 수량 크기가 함께 움직이므로 원인을 분기 하나로 확정할 수는 없다.

출력 합산을 항상8로 나누는 구현도 확인했다. 하지만 학습된 출력 가중치가 배율을 보상할 수 있으므로 '/8 때문에 실패했다'는 결론은 현재 근거를 넘는다. 장기 분기의 미사용 자체도 오류나 정보 손실의 증명이 아니다.

## 4. RMSE로 고르는 규칙에서 MAE 상충이 커진다

저장된5seed epoch 이력만 비교했다. 실제 checkpoint를 다시 선택하거나 평가하지 않았다.

| 모델 | 고정 RMSE 선택의 평균 RMSE / MAE | 저장 이력상 MAE 최소 epoch들의 평균 RMSE / MAE |
|---|---:|---:|
| 공유형 | 33.908969 / 9.315902 | 35.000600 / 9.036259 |
| RMTPP | 34.507154 / 9.122804 | 35.215423 / 9.013897 |
| S2P2 | 33.964727 / 9.254162 | 34.946255 / 9.011741 |

공유형은 RMSE 선택점에서 자기 저장 이력의 MAE 최소값보다 평균0.279643 높다. RMTPP는0.108907이다. 모델 전체의 MAE가 언제나 같은 정도로 나쁜 것이 아니라, 좋은 RMSE를 택하는 위치에서의 상충도 크다. MAE 기준 선택으로 바꾸면 RMSE가 나빠지는 이력이 함께 보인다. 이 사후 비교를 checkpoint 변경 근거나 미관측 구간 성능 개선으로 해석하면 안 된다.

## 확인되지 않은 설명과 배제한 설명

- Validation에서 전체 수량 수준이나 q>200 발생 비율이 커졌다는 근거는 없다. Train 전체 양성 이벤트 평균14.504→Validation12.765이며 중앙값2·Q3=10은 같다. Train/Validation 타깃의 q>200 비율도0.795%→0.747%다. 이 평균·비율만으로 개별 극단값 크기의 모든 변화를 배제하지는 않는다.
- 신규 부품0, 부품·월 중복0, delta_t와 월 인덱스 차분 불일치0이다. 관측 길이84/기간84 제한 때문에 Train/Validation 이력이 잘리는 경우도 없다.
- 큰 수량을 전부 무작위 돌발값이라고 할 수 없다. Validation 큰 수량 행의 직전 수량 중앙값은100이며28%는 직전에도200초과였다.
- 원자료의 부품 설명·가격·조달기간은 현재 모델 입력에 없다. 이런 외생정보의 누락이 상대순위를 설명하는지는 미확인이다. 동일 입력의 외부 모델에도 공통인 제약이다.
- 현재 공유형의 Train 개별예측이 없으므로 raw수량 기준 과적합·과소적합을 확정하지 않는다. 저장 학습의 log수량 손실도 Validation보다 항상 낮은 형태가 아니므로 단순한 과적합 설명을 입증하지 못한다.

## 다음에 먼저 구별할 질문

1. **우선순위1 — 급락 대응과 큰 수량 과소예측의 균형:** 큰 수량을 조금 더 높게 예측하는 이득을 유지하면서, 큰 관측 뒤 수량이 내려가는 구간의 과대예측을 줄일 수 있는가? 현재 상대MAE 손해가 가장 구체적으로 확인된 질문이다.
2. **우선순위2 — 희소 이력에서 드문 분기 조합의 영향:** 이력 길이·수량 수준을 맞춘 상태에서도 lag8 분기 활성 구간의 약점이 남는가? 현재 상관관계를 메커니즘으로 설명하려면 구별 가능한 대조가 필요하다. 활성 분모 변경이나 분기 삭제를 바로 정당화하지 않는다.
3. **우선순위3 — 목적·선택 규칙의 상충:** 고정된 공통 조건에서 수량 수준과 급락의 균형이 개선되는지 본다. 새 가중치나 RAF 전용 손실을 임의 튜닝하는 작업은 이번 분석에 포함하지 않았다.

새 학습은 시작하지 않았다. 이번 진단은 'RAF는 예측 불가능하다'가 아니라, **드문 큰 수량이 RMSE를 좌우하고, 공유형은 급락 뒤 과대예측과 희소 이력의 분기 사용 변화에 상대적 약점이 관측된다**는 범위까지 지지한다.
