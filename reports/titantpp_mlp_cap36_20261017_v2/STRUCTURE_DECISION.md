# Cap36 네 구조의 Validation/Test 비교와 후속 판단

**대조군의 실제 의미 확인 — 완료**

앞선 답변에서 AllAvailable을 “전체 이력 대조군”이라고 설명한 명칭은 정정한다. 동결 계약과 관련4개 소스SHA를 확인했다.

- MLP4/MLP16: 첫 Encoder의 현재·직전 관측 표현을 사용하며, 폭은 각각4/16이다. 관측개수1·2·4·8·16·32·64·128을 넘는지에 따라8개 분기를 켠다. 각 분기가 사용하는 과거는 모두 직전 관측 하나이며 고정8로 나눠 합친다.
- AllAvailable: 같은 폭4·현재/직전 입력을 유지하고 직전 관측이 존재하면8개 분기를 모두 켠다. 추가 가중치는MLP4와 같은6144개다. 전체이력 평균이나 더 먼 과거 입력을 추가한 구조가 아니다.
- CurrentOnly: 추가 분기에 첫 Encoder의 현재 hidden만 넣고 폭6으로6144개 추가 가중치를 맞춘 대조군이다. 원래8개 분기 가용 조건과 공통attention/memory의 이력 처리는 유지한다. 모델 전체에서 과거를 제거한 구조가 아니다.

**이어갈 근거와 우선순위 — 완료**

1. Intermittent AllAvailable은 후속 저장예측 분석의1순위다. MLP4 대비 평균변화는Validation RMSE−5.26%/MAE−2.19%,Test−2.78%/−4.42%다. MLP16 대비Test의 두 지표가3seed 모두 개선된다. 그러나MLP4대비4개지표가 같은seed에서 모두 개선된 경우는0개이며 TestRMSE 평균개선은seed42가 이끈다. 가용성 조건과 관측길이별 결과를 검토할 근거이며 “긴 이력이 유리하다”거나 즉시공통채택할 근거는 아니다.
2. RAF MLP16은2순위 용량후보다. TestRMSE−0.32%/MAE−1.43%이며3seed 모두 개선됐다. ValidationRMSE평균+0.039%악화와seed42/52예외를 남긴다. 네평균조건을 모두통과한 것으로 부르지 않는다.
3. Taxi는MLP4참조를 유지한다. MLP16은Validation 두평균이 모두악화했고 Test도RMSE개선과MAE악화가 갈린다. AllAvailable은seed42만네지표모두개선,52·62는네지표모두악화다. 공통변경채택 근거가 약하다.
4. CurrentOnly는우선순위가낮다. Intermittent TestRMSE평균최저만으로는Validation과TestMAE악화를상쇄하지 않는다. RAF의MAE는두split3seed모두MLP4/16보다나쁘고,TaxiTest는3seed모두MLP16보다두지표가나쁘다.

**남은 검토 순서 — 다음 작업**

Intermittent의AllAvailable−MLP4 결과를 관측길이·Cap상한집단별로 나눠seed42이득과52·62악화를 먼저 확인한다. 이어RAF MLP16의Test 일관개선과Validation 예외를 살핀다. 이 단계는 후속 검토 제안이며 새 학습이나 재추론을 실행하지 않았다.

네구조 중 세데이터셋·두split·두지표를 함께개선하는 공통승자는없다. 외부비교군의Cap재학습결과가없으므로기존 외부최우수대비 통과여부는 미검증이다. 기존Test를 본후의탐색적해석이며 독립일반화·통계유의성·원인확정으로확대하지 않는다. 같은dataset·seed는같은GPU지만Intermittent42=5080/cuDNN91900,52·62=5090/cuDNN92000이라는한계가있다.
