# 기존 Test 전체·기간·수량·이력 구간 분석

사용자 승인: 2026-10-03, 직전 제안인 기존 Test 전체 결과 유지와 기간별·수량별·이력별 추가 분석에 대해 “진행하자”.

## 현재 기준선

- 입력은 `reports/titantpp_legacy_evaluation_20261003_v1`의 완료된 108조건 Test 예측 원본이다.
- Taxi·Intermittent·Instacart·RAF, 9개 학습 모델 × seed42/52/62와 두 결정적 수량 기준선을 모두 포함한다. S2P2와 두 구조 대조군을 유지한다.
- 기존 비교군 범위에 따라 Deep Renewal은 포함되지 않는다. 제외 결정은 결과 확인 이후였으며 이 범위는 모든 수요 예측기 대비 우월성의 근거가 아니다. 별도 B 평가와 A100 후보를 이번 고정 비교표에 섞지 않는다.
- 새 학습·추론·원격 실행·임대·Test 대상 변경·선택 checkpoint 변경을 수행하지 않는다. 이번 분석은 로컬 저장 예측을 재집계한다.
- 기존 전체 결과와 원고를 덮어쓰지 않는다. 새 독립 Test를 확보한 것으로 표현하지 않는다.

## 분석 기준 고정

`freeze_contract.py`는 기존 모집단 manifest와 validation replay에 저장된 경계를 읽어 `analysis_contract.json`을 작성한다. 기존 전체 Test 결과는 이미 알려진 상태지만, 새로운 구간별 결과를 계산하기 전에 아래 규칙을 고정한다.

1. 전체 Test: 기존 모든 대상과 이벤트 가중치 유지.
2. 시간: Test 기록의 최소~최대 native-time 격자를 세 구간으로 나눈다. 날짜를 숫자 YYYYMMDD 자체로 나누지 않고 Taxi는 시간, Intermittent는 주, RAF는 월 좌표를 사용한다. 동일 시각을 나누지 않으며 표본 수는 같지 않을 수 있다.
3. Instacart 시간: 사용자 구매 시작 후의 기록 경과일을 세 구간으로 나눈다. 공통 달력이나 각 사용자의 Test 진행률을 뜻하지 않는다.
4. 수량: 기존 모든 train 행에서 정한 수량 경계를 재사용한다. 경계값은 아래 구간에 포함한다.
5. 이력: 기존 고정 이력 경계를 재사용한다. RAF 등에서 빈 구간은 제거하지 않고 지표를 미정의로 남긴다.
6. 세부 이력: 기존 분기 활성화 기준에서 유도한 공통 경계 `[1,3,7,15,31,63,127]`을 보조 표에 적용한다. 실제 입력 이력 사건 수이며 생애 전체 이력이나 경과 시간이 아니다.

모든 모델·seed에 동일한 대상→구간 대응을 적용한다. 수량 구간은 target의 실제 수량을 사용한 사후 오차 설명이며 예측 시 사용되는 정보나 모델 선택 규칙이 아니다. 시간 구간별 개체 구성도 달라질 수 있으므로 결과 차이를 분포 이동의 인과적 증거로 단정하지 않는다.

## 집계와 검증

- 각 seed에서 MAE와 `sqrt(SSE/N)`를 먼저 계산한 뒤 세 seed의 평균·표본 표준편차(ddof=1)를 계산한다. 예측 앙상블이나 구간 RMSE의 단순 평균을 사용하지 않는다.
- 구간별 N·절대 오차 합·제곱 오차 합·시간 NLL 합·signed error 합이 전체 Test로 복원되는지 확인한다.
- 모든 예측 조각의 SHA와 receipt, 대상·정답·이력의 일치를 확인한다. 누락 조건을 유리한 교집합으로 대체하지 않는다.
- 전체 지표는 이전 `analysis.json`의 seed별 값·평균·표본 표준편차와 대조한다.
- seed 표준편차는 신뢰구간이 아니다. 새 구간 분석은 기술적 탐색으로 보고하며 새 p값·신뢰구간을 만들지 않는다. 기존 전체 Test 불확실성 결과는 원래 보고서에 유지한다.
- 결정적 두 기준에는 하나의 예측 벡터만 사용한다. 시간 NLL과 seed 표준편차를 부여하지 않는다.
