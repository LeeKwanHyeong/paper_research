## 방법론 판정과 한계 — 완료

- Temporal−Current 평균은 Validation RMSE +0.006033/MAE −0.026242, Test RMSE −0.006931/MAE −0.045582다. MAE는 두 split의 모든 seed에서 개선했다. RMSE는 seed42만 개선하고52·62는 악화했다. 사전 기준인 Validation 두 지표 동시 개선은 충족하지 못했다.
- Temporal−기존 CNN 평균은 Validation RMSE +0.040666/MAE +0.005325, Test RMSE −0.056538/MAE +0.020016이다. Test seed52는 두 지표 모두 악화했고62는 RMSE 개선/MAE 악화였다. 일부 성능 이득은 있으나 전체 채택 기준을 충족한 backbone 개선으로 결론 내리지 않는다.
- Temporal의 큰수량 RMSE·MAE 평균은 두 split에서 Current보다 높고, 전체·큰수량 TimeNLL 평균은 낮다. Current의 Test 큰수량 TimeNLL은 기존 CNN보다 높다. 불리한 결과를 제외하지 않았다.
- 기존 CNN/외부는5080·cuDNN91900, 신규 후보는5090·cuDNN92000이다. 같은 파라미터 수는 같은 함수공간·최적화를 뜻하지 않는다. 공통 가중치가 함께 학습되고 메모리 검색도 달라질 수 있으므로 FFN의 독립 인과효과를 확정하지 않는다.
- 기존 Test 결과를 참고한 탐색적 후속 평가다. 새 독립 평가·보편적 일반화 개선·통계 유의성을 주장하지 않는다. checkpoint는 Validation에서 고정했고 Test로 다시 선택하지 않았다.
