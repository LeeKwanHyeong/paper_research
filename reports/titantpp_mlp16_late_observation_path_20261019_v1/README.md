# 후기 관측 경로 — 로컬 준비 완료

**구조와 구현 — 완료**

기존 이력 MLP16의 두 Encoder 출력 h2 뒤, 기존 정적 메모리 앞에 `P(e0)`를 더하는 후보와 `P(h2)`를 더하는 대조군을 준비했다. e0는 각 유효 관측의 기존 시간·수량 투영이며 위치 임베딩 전 값이다. 예측에서는 기존 마지막 관측 위치를 사용한다. 두 새 경로는 폭8·추가 가중치1,024개로 같고 출력0 초기화에서 기존 MLP16과 같은 예측을 낸다.

**합성 검증 — 완료**

CPU 단위 검사15개와 두 후보×세 수량 목적의 합성 통합 조건6개가 통과했다. 미래 target·withheld·padding 차단, 초기 동등성·gradient·저장/복원·시간 전용 head 불변을 확인했다. 독립 구현 읽기검토의 중간 이상 발견은0이다. 합성 optimizer step은 가짜 입력 검사이며 실제 학습 fit으로 세지 않는다. 초기 테스트 fixture 실패 기록도 별도로 보존했다.

**현재 실험과 기존 결과 — 유지**

기존 source952 및 후속 source955의 모든 파일 SHA와 원시간27 준비 봉인을 재검증했다. 기존 CNN·현재 손실18·대기 원시간27·공용 Runtime·원격 작업은 바꾸지 않았다. 새 학습·실데이터 추론·Test·원격 호출은0이다.

**새 학습 — 미시작 / 공통 조건 결정 대기**

진행 중인 손실 비교와 승인된 원시간27 결과를 본 뒤 두 후보·참조에 동일한 입력·손실 조건을 확정한다. 실행 계약·host 배정·native GPU 검증은 아직 없다. 사용자가 새 학습을 결정한 뒤 별도로 준비하며 자동 대기열은 추가하지 않았다. 예정 범위는 두 후보×세 데이터×3seed=18개다. 기존 참조는 조건이 실제로 같은 경우에만 재사용한다.

**판정할 내용 — 향후 Validation 비교**

원관측 경로가 기존 참조와 같은 명목 용량의 문맥 경로보다 세 데이터에서 두 지표 평균을 함께 낮추는지 확인한다. 모든 seed 예외를 남긴다. 기존 residual도 입력을 전달하므로 정보 소실을 전제하지 않는다. 메모리 검색도 함께 달라질 수 있으며, 이 경로 자체를 새로운 잔차 원리나 검증된 backbone 개선이라고 부르지 않는다.
