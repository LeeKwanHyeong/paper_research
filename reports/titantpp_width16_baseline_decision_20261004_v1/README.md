# 후속 실험 기본 기준선: TitanTPP History MLP 폭16

**상태: 사용자 결정 반영 완료.** 2026-10-04 사용자가 “기본 베이스라인을 폭16으로 고정하자”라고 지시했다. 후속 폭 비교와 CNN·GRU 구조 실험은 `titantpp_history_mlp_width16`을 기본 비교 기준으로 삼는다.

| 항목 | 고정한 기준 |
|---|---|
| 모델 ID | `titantpp_history_mlp_width16` |
| 전체 표현 | 64차원 유지 |
| MLP 보정 | 독립 8분기, 각 `128→16→64`, bias 없는 GELU |
| 보정 파라미터 | 24,576개 |
| 분기 처리 | 기존 관측 이력 가용성, 합산 후 고정 `/8` |

## 완료된 기준선 재사용

완료된 12조건의 source·선택 체크포인트·Validation/Test를 재사용한다. 조건별 epoch와 checkpoint/state SHA는 [결정 JSON](decision.json)에 원본 registry와 함께 연결했다. 다시 학습하거나 Test에 따라 epoch를 바꾸는 결정이 아니다.

폭4는 기존 구조·용량 대조군으로 보존한다. 폭8·12는 예정된 용량 대조군이며 현재 구현·학습 완료로 표시하지 않는다. 기존 `titantpp_history_mlp` ID의 내부 폭을 변경하면 원래 폭4 checkpoint의 weight shape와 identity가 달라지므로, 별도 폭16 ID를 사용한다.

이 선택은 사용자가 정한 후속 실험 기준이다. 폭16이 모든 데이터·지표에서 최선이라는 과학 판정은 아니다. 이미 확인한 불리한 결과와 seed별 차이는 [전체 비교 보고서](../titantpp_completed_validation_test_20261004_v1/README.md)에 그대로 남는다. 그 보고서의 앞선 “폭16 고정 보류” 권고는 이번 사용자 결정으로 후속 운영 기준에서 대체되며, 수치·평가 계약·감사 기록은 변경하지 않는다.

## CNN·GRU와 파라미터 비교

CNN만 추가한 후보는 기존 폭16 MLP를 유지해 CNN 효과를 확인한다. GRU 대체 후보와 CNN+GRU 후보도 폭16 기준선과 비교하되, GRU 폭과 residual 계수·활성 조건·파라미터 예산은 별도로 확정한다. MLP 분기 폭16을 선택했다고 GRU 잠재 폭까지 자동으로 16이 되는 것은 아니다.

이전 [CNN·GRU 검토](../titantpp_cnn_gru_review_20261003_v1/README.md)의 GRU r=24 근접 용량 표는 폭4의 보정 6,144개를 기준으로 한 제안이다. 폭16의 보정 24,576개에 대해서는 같은 근접 용량 주장으로 재사용하지 않는다.

전체 모델의 정확한 파라미터 수는 위치 embedding의 `max_len` 등 원래 source 설정에 따라 달라진다. 114,435개는 `max_len=256`의 폭16 참조값이며 모든 데이터의 공통 총수로 고정하지 않는다. 동일한 나머지 설정에서 폭4→16의 증가분은 18,432개다. 후속 계산 효율 대조에서는 데이터별 실제 전체 파라미터와 같은 Runtime의 시간을 기록한다.

## 남은 작업 순서

**1. 폭8·12를 폭16 기준의 용량 대조에 연결한다 — 다음 작업**

- 대상: `paper_research`의 폭별 모델 identity·구현·실행 계약과 예정된 5080·5090 조건.
- 기존 폭4·16은 재사용하고, 분기 가용성·`/8`·초기화·출력부·손실·선택 기준을 유지한다.
- 완료 조건: 네 폭의 차이를 용량 효과로 비교할 수 있도록 구현·계약 검증이 준비된 상태.

**2. CNN·GRU 대조 계약을 폭16에 맞춘다 — 다음 작업 / 기준 계약 이후**

- 대상: Encoder 1 CNN, 중간 GRU, 결합 후보. CNN만·GRU만·CNN+GRU의 차이를 구분한다.
- 과거 참조 범위·잠재 폭·삽입 위치·개체별 상태 reset·padding·초기 항등·파라미터 예산을 정한다.
- 폭 대조와 독립적인 설계 검토는 병렬로 할 수 있으나 같은 모델·factory 파일 구현은 소유권을 나눠 충돌 없이 진행한다.
- 완료 조건: 기존 폭16 대비 변경 표와 인과성·계약 테스트가 마련된 상태.

**3. 원고의 대표 모델과 비교표를 연결한다 — 다음 작업 / 검증된 계약 이후**

- 대상: 현재 LNCS 원고의 본문·구조 그림·Appendix.
- 폭16을 후속 기준선으로 명시하고 폭4·8·12 대조와 수량·시간 지표의 장단점을 함께 설명한다.
- 완료 조건: 모델 이름·분기 폭·파라미터 수·숫자가 실제 source 및 split에 일치하는 상태.

이번 변경은 로컬 기준선 기록과 운영 인덱스 갱신이다. 신규 GPU 학습·원격 실행·Runtime 변경은 포함하지 않는다.
