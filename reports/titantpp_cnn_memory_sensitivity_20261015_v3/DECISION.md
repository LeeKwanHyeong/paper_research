# CNN 메모리 감쇠 진단 결과와 후속 판단

고정 CNN의 Train·Validation 진단은 완료했다. 현재 결과는 메모리를 일괄적으로 줄이는 개선안을 지지하지 않는다. 상황별 gate의 효과는 아직 검증하지 않았으며, 이번 진단을 학습된 gate의 실패로 부르면 안 된다.

## 현재 기준선 — 완료

- Taxi·RAF·Intermittent 각각 seed42/52/62의 기존 CNN 선택 checkpoint를 고정했다.
- 추론 시 메모리 잔차에만 alpha=1, 0.5, 0.25, 0을 적용했다. alpha1은 기존 CNN, alpha0은 해당 메모리 잔차 제거다.
- 9개 모델의 Train·Validation에서 총72조건을 평가했다. Validation9의 기존 여섯 지표 재현, 파라미터 불변, worker18 실제 exit0, dispatcher2 실제 exit0, 회수 manifest322개 SHA 검증을 완료했다.
- 기존 CNN·FULL·CAP 결과를 교체하지 않았다. 이 진단은 Test를 확인한 뒤 설계된 탐색적 후속 작업이며 새 독립 평가가 아니다.

## 전체 오류 — 완료

아래 값은 전체 raw 수량 **Validation RMSE의 3seed 평균 ± 표본 SD**다.

| 데이터셋 | 기존 CNN (alpha1) | 절반 반영 (alpha0.5) | 1/4 반영 (alpha0.25) | 메모리 제거 (alpha0) |
|---|---:|---:|---:|---:|
| Taxi | 86.650 ± 2.099 | 99.401 ± 6.254 | 113.246 ± 15.815 | 130.522 ± 27.494 |
| RAF | 34.431 ± 0.073 | 34.507 ± 0.081 | 34.547 ± 0.084 | 34.589 ± 0.087 |
| Intermittent | 1.723 ± 0.073 | 2.562 ± 0.492 | 3.427 ± 0.895 | 4.398 ± 1.341 |

감쇠한 27개 dataset·seed·alpha 조건 모두 각자의 alpha1보다 Validation RMSE가 높다. alpha0.5의 평균 RMSE 증가율은 Taxi14.716%, RAF0.220%, Intermittent48.681%다.

| 데이터셋 | Validation MAE: 기존 CNN | Validation MAE: alpha0.5 | Train RMSE: 기존 CNN → alpha0.5 |
|---|---:|---:|---:|
| Taxi | 27.793 ± 0.500 | 31.473 ± 1.485 | 85.135 → 94.363 |
| RAF | 9.218 ± 0.028 | 9.199 ± 0.030 | 45.952 → 46.053 |
| Intermittent | 0.736 ± 0.061 | 0.988 ± 0.154 | 1.539 → 2.242 |

RAF의 MAE는 소폭 개선되지만 주지표 RMSE와 큰 수량 RMSE는 악화된다. Taxi의 alpha0.5에서는 큰 수량 RMSE가 416.209→412.028, 큰 수량 MAE가 334.006→313.614로 감소하지만 전체 RMSE·MAE는 높아진다. 전체 TimeNLL 평균은 세 데이터셋에서 모두 감소한다. 이 상충 결과를 포함한 여섯 지표 전체를 SUMMARY에 보존했다.

## 이력 조건별 차이 — 완료

Train에서 정한 사분위 경계를 Validation에 적용했다. 전체 감쇠 기준과 별개로, 같은 특징·같은 구간 쌍에서 감쇠의 MSE 개선·악화가 2seed 이상 반복되는 쌍은51개다. 서로 겹치는 특징·alpha·구간의 탐색 결과이며 51개의 독립 증거나 통계적 유의성을 뜻하지 않는다.

예를 들어 Taxi의 메모리 벡터/기본 표현 노름 비율이 Train 상위 사분위 경계를 넘는 행에서 alpha0.5를 적용하면 다음과 같다. 차이는 감쇠−기존 CNN이다.

| seed | Validation 대상 수 | 구간 MSE 차이 | 구간 MAE 차이 |
|---|---:|---:|---:|
| 42 | 2,013 | -0.3070 | +0.0286 |
| 52 | 1,847 | -0.1908 | +0.0291 |
| 62 | 1,918 | -0.1797 | +0.0487 |

같은 비율의 하위 사분위 구간에서는 MSE가 각각 +15,307.35, +8,171.55, +3,948.60 증가한다. 즉 조건별 반응은 다르지만, 위 상위 구간의 MSE 개선은 작고 MAE는 세 seed 모두 악화된다. 이것만으로 복잡한 gate의 실질적인 전체 성능 개선을 예상하기는 어렵다. 유사도나 노름 비율을 메모리의 유용성 그 자체로 해석하지 않는다.

## 학습 진입 판단 — 다음 작업 보류

실행 전에 기록한 보수적 기준은 **Validation 평균 RMSE 1% 이상 감소 + 2/3seed 이상 개선**이었다. 상황별 gate 진입에도 이 조건을 요구했으므로 두 기준 모두 미충족이다. 이 기준을 결과에 맞춰 바꾸어 통과로 표시하지 않으며, 이번에는 새 학습을 실행하지 않았다.

다만 고정 감쇠의 전체 이득은 상황별 gate의 논리적 필요조건이 아니다. 따라서 정확한 결론은 **일괄 감쇠를 개선안으로 채택할 근거가 없고, gate의 유효성은 미확인**이라는 것이다. 이미 학습된 표현에 추론 시 개입한 결과이므로, 처음부터 감쇠·gate를 포함해 학습한 모델의 성능을 직접 예측할 수도 없다.

후속 우선순위는 새 학습 규모를 늘리는 것보다, 위 조건별 이득이 실제로 전체 오류를 줄일 만큼 큰지와 사용할 관측 특징을 정리하는 것이다. 후속 규칙·모델을 이 Validation 결과를 보고 설계한다면 추가 적응 이력을 명시해야 한다. 현재 Test를 다시 보며 설계를 조정하지 않는다.

서버별 최대3개 실행기는 구현·검증됐다. 이번 고정 모델 진단은 원래 native Runtime에 맞춰 5080에7개 모델, 5090에2개 모델을 배정했다. 후속 신규 학습의 배치는 최대3개씩 가능하도록 유지하며, 5090에 이번 배정이2개였던 것을 순차 실행으로 바꾸지 않는다.

Intermittent42/52는 5090/cuDNN92000, seed62는 5080/cuDNN91900이다. 시간은 host별로 분리 기록했다. source·checkpoint·계약·실행 오류 이력과 전체 결과를 별도 경로로 보존했다.
