# 같은 개체·수량·변화 폭 안의 CNN 오류 비교

Material Passport: academic-research-suite / experiment-agent / local matched analysis / 2026-10-15 v1.

## 비교 대상을 맞춘다 — 분석 전에 고정

- 기존 동결 CNN 9개의 Train·Validation 저장 예측 중 alpha=1만 사용한다. 원본 SHA와 seed 간 동일 대상·이력·정답을 검증한다. Test, 원고, 원격, 새 추론·학습은 사용하지 않는다.
- 방향은 마지막 두 **관측** 수량의 log1p 차이 부호다. 정답 수량·예측 오차는 매칭에 사용하지 않는다. 변화 없음과 이전 관측 없음은 이 비교에서 제외하고 제외 수를 기록한다.
- 같은 split에서 `개체 ID × 기존 Train 수량 사분위 × floor(log1p(마지막 관측 수량)/0.1) × floor(abs(관측 log 변화)/0.05)`가 같은 셀을 만든다. 수량과 변화 폭의 bin 원점은 0으로 고정하며 Validation으로 경계를 맞추지 않는다. 셀 내부 수량+1의 비율 차이는 최대 exp(0.1), 변화 log 크기 차이는 0.05 미만이다.
- 상승·하락이 모두 있는 셀만 남긴다. 각 방향의 셀 가중치 합을 min(n_상승,n_하락)로 맞춘다. 따라서 두 방향의 개체·수량 구간·변화 폭 구간 구성이 정확히 같다. 개별 행 가중치, 대상 ID와 셀을 저장한다. 전체와 네 사분위를 모두 보고한다.
- 추가로 각 사분위에서 Train·Validation 모두에 남는 개체만 유지하고, 개체별 가중치 합을 1로 맞춘다. 이 민감도 분석은 두 split 및 두 방향에서 같은 개체 구성·가중치를 사용한다. 셀의 세부 구성까지 split 간 같다는 뜻은 아니다.
- 연속값의 잔여 차이를 가중 평균 차이와 표준화 평균 차이(SMD)로 보고한다. 매칭 전후 대상·개체 수, 남은 비율, 유효 표본크기(ESS)를 기록한다. 낮은 포함률을 전체 데이터의 근거로 확대하지 않는다.

## 차이가 남는지 판단한다 — 후속 구현에 한정

앞선 사분위 분석의 10% 운영 기준은 미충족 그대로 보존한다. 이번 질문은 사용자가 추가로 요청한 개체·변화 폭 통제 뒤의 **차이 유지 여부**이며, 앞선 기준을 통과했다고 재표기하지 않는다.

이미 관찰한 Taxi 상위 수량 사분위를 주 대상으로 고정한다. 각 split에서 방향별 매칭 가중치 합 50 이상·개체 5개 이상이고, log 수량 및 변화 폭의 |SMD|≤0.1인 경우를 해석 가능한 비교로 본다. 하락−상승 bias 차이가 Train·Validation 및 공통 개체 민감도에서 양수로 유지되는 seed가 2개 이상이면 계약·구현·합성 검증을 준비할 탐색적 근거로 삼는다. 효과 크기와 RMSE·MAE 차이도 그대로 보고하며 성능 개선·통계적 유의성 기준으로 사용하지 않는다. 실패하면 구간이나 폭을 다시 조절해 통과시키지 않는다.

관측 이력·타깃은 시간적으로 연관되어 있고 측정하지 않은 조건 차이가 남는다. 현재의 오류 대비는 CNN 내부 필터가 원인이라는 증명이 아니다. 구현하더라도 **새 학습은 결과 보고 후 사용자가 결정**한다.
