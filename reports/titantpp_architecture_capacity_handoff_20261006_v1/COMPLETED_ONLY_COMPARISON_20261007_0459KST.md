## 사실과 해석의 경계

- 명시적 이력 보정은 Taxi·RAF의 모든 seed에서 prototype 유무 양쪽의 전체 수량 RMSE를 개선한다(P0_H1−P0_H0, P1_H1−P1_H0). 같은 용량의 현재 상태 보정보다 P1_H1이 좋아, 단순 용량 추가만으로 설명하기 어려운 근거가 있다. 입력 정보·초기 잔차 분포 차이까지 완전히 제거한 인과 증명은 아니다.
- prototype의 필수성과 일반 FFN 대비 이점은 다르다. Taxi에서 P1_H1은 P0_H1보다 seed52/62의 전체 RMSE가 나쁘며, 3seed 평균은 77.735158 대 77.377287이다. 대신 평균 전체 MAE·큰 수량 RMSE/MAE와 RMSE의 표본 표준편차는 낮다. RAF는 prototype 추가 시 모든 seed의 전체 RMSE가 낮지만 평균 차이는 0.040827로 작다. prototype만 쓰는 P1_H0는 Taxi의 모든 seed에서 P0_H0보다 전체 RMSE가 나쁘다.
- 손해도 함께 보고한다. Taxi의 P1_H1은 PF_H1보다 전체 RMSE가 낮지만 큰 수량 RMSE는 376.659642 대 366.708633, 큰 수량 MAE는 296.101440 대 287.777210, 전체 TimeNLL은 1.229372 대 1.154620으로 악화된다. RAF에서도 PF_H1보다 전체 RMSE가 낮지만 전체 MAE는 9.266293 대 9.188581, 전체 TimeNLL은 3.551653 대 3.469797, 큰 수량 TimeNLL은 3.579525 대 3.335558로 악화된다.
- 현재 근거는 명시적 이력 보정과 특정 검색 대조의 수량 중심 효과다. 모든 지표의 우월성, 보편적인 prototype 필수성, 시너지·외부 우월성·독립 Test 확정으로 확대하지 않는다. 선택 기준과 대표 모델은 이번 중간 결과로 변경하지 않았다.
