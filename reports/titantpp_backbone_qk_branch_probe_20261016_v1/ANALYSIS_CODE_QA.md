# Q/K on/off 분석 코드 검토

상태: **분석 코드·합성 계산 PASS**. 실제 진단이나 결과 분석 완료를 뜻하지 않는다. 명세 작성자가 부모 에이전트가 작성한 분석 코드를 별도로 검토했으며, 독립 과학 설계 검토로 부르지 않는다.

## 확인한 내용

- 비교 대상은 새 진단의 동일 checkpoint on/off 행이다. 기존 CNN·과거 V 후보의 예측 행을 읽거나 모델을 실행하지 않았다.
- source143과 선택 epoch 5/5/22, 새 target scheme, 예측 상태·Runtime 불변 및 완료 증적 검증을 거쳐 행을 읽는다. 서로 다른 native/exporter target digest를 직접 비교하지 않는다.
- 고정 15개 조건, 기존 Train Q25/Q75와 조건별 공통 개체 가중을 유지한다. 각 조건의 공통 개체 집합이 다르므로 가중 조건 합을 전체로 해석하지 않는다.
- off−on 방향과 공개 결과의 on/off 명칭을 확인했다. 기존 CNN이나 Q/K 없이 다시 학습한 모델로 off를 설명하지 않는다.
- 모든 seed·악화·빈 조건·제외 행과 전체/큰 수량/시간 지표를 보존한다. AE·SE·부호오차 합의 가산 일치를 검사하며 RMSE를 가산 분해하지 않는다.

## 합성 검증

새 검사 8개와 기존 순수 계산 검사 7개, 총 **15 tests actual exit0**. 별도의 결정적 무작위 cohort 30개에서 공통/분리 개체, 불균등 행 수, 양·음 오차, 빈 조건을 포함해 **41,400개 스칼라 assertion**을 확인했다. 무작위 검사 전후 분석·검사·순수 함수 네 파일의 SHA가 동일했다. 중대 불일치는 발견하지 않았다.

## 한계와 다음 작업

실제 입력·예측 행, checkpoint 역직렬화, native 실행과 완료 receipt 연결은 실행하지 않았다. 운영 코드의 독립 검증과 native gate 통과가 먼저 필요하다. 그 뒤 고정 분석을 한 번 실행하고 출력 수량·SHA를 재검증한다. 이번 결과는 같은 공동 학습 모델의 분기 민감도 분석 도구에 대한 검토이며, 구조의 개선이나 원인 확정을 보장하지 않는다.
