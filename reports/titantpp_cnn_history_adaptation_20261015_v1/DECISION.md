# 이력 적응 CNN 준비 여부

Material Passport: academic-research-suite / experiment-agent / local analysis; 2026-10-15; v1. 저장된 예측의 집계는 검증 완료, 새 구조의 효과는 미검증.

## 확인한 작업 — 완료

기존 CNN 9개 선택 모델의 Train·Validation 예측 18묶음, 총1,677,717개 seed별 예측 행을 분석했다. 같은 데이터셋·split에서 세 seed의 대상과 관측 특징이 정확히 일치했다. 서로 독립적인 1,677,717개 데이터 표본이라는 뜻은 아니다. 240개 입력 증적 파일의 SHA를 검사했고 전체 RMSE·MAE·TimeNLL을 기존 receipt와 재계산 대조했다. 큰 수량을 포함한 여섯 지표는 선택 checkpoint별로 보존했다.

분석은 메모리 진단 artifact의 alpha=1 기존 CNN 예측만 사용했다. 새 예측/학습/원격 실행/Test 열람은 없으며 원본 checkpoint·source·입력·손실·head와 기존 결과를 바꾸지 않았다. Python 단위 검증7개는 합성 데이터만 사용해 통과했다.

## 오류 양상 — 관측 사실

최근 두 관측 수량이 하락한 Taxi Validation 행에서 CNN의 평균 bias는 +10.3784, 상승한 행에서는 −0.5298이다. bias는 예측−실제이며, 평균 ± 표본SD를 포함한 전체 결과는 `analysis/ANALYSIS.md`에 있다. 해당 RMSE는 각각88.7509와105.9498이므로 **하락 조건의 과대 예측이 있다는 사실이 하락 조건의 RMSE가 더 크다는 뜻은 아니다.**

마지막 관측 수량의 Train 사분위 경계는2·7·65다. 마지막 수량>65인 상위 사분위 안에서 하락−상승 조건의 bias 차이를 보면 다음과 같다.

| seed | Train bias 차이 | Validation bias 차이 | Train: 차이/두 조건 합산 MAE | Validation: 차이/두 조건 합산 MAE |
|---|---:|---:|---:|---:|
| 42 | +7.8790 | +29.4909 | 8.14% | 29.62% |
| 52 | +33.3350 | +59.3823 | 34.40% | 57.82% |
| 62 | +1.6336 | +24.9283 | 1.71% | 24.27% |

상위 구간의 비교 대상은 Train 하락4,658행/40개체·상승4,818행/41개체, Validation 하락974행/29개체·상승954행/34개체다. 이 방향 차이는 세 seed 모두 Train·Validation에서 반복된다. 따라서 **관측 이력과 오류 사이의 단서가 없다고 결론 내리지 않는다.** 다만 Train 효과 크기가 seed별로 크게 다르고 Validation에서 차이가 커졌다.

하위 세 수준 구간은 Train→Validation의 bias 차이 방향이 seed별로 뒤집히거나 작다. 같은 구간에서 두 split의 방향과 크기가 일관된 seed는 사전에 정한 기준으로 각0·1·1개였다. 상위 구간도1개뿐이었다.

RAF와 Intermittent에서도 이력 방향별 오류는 다르지만, Taxi에 대해 정한 주 분석 기준을 다른 데이터셋/보조 특징으로 사후 교체해 통과시키지 않는다. 모든 구간·seed·미확인 조건은 `analysis/SEED_CELLS.csv`와 JSON에 보존했다.

## 구현 진입 판단 — 다음 작업 보류

분석 전에 이 세션이 정한 운영 기준은 같은 과거 수량 구간의 상승/하락 조건에 각각50행·5개체 이상이 있고, bias 차이가 합산 MAE의10% 이상이며, Train·Validation에서 같은 방향으로2/3seed 이상 반복되는 것이었다. **사용자가 별도로 승인한 성능 기준이나 통계 검정이 아니다.** 이번 실행에서 그 기준은 충족되지 않았다.

따라서 결과를 본 뒤 기준을 낮추어 통과로 바꾸지 않고, 이력 적응 CNN과 용량 대조군의 새 학습 계약·모델 구현은 만들지 않았다. 현재 완료한 구현은 **기존 예측 분석 도구와 합성 검증**이다. 새 구조가 실패했다는 판정도 아니며, 새 학습을 허가하는 결과도 아니다.

## 해석 범위

- 큰 수량에서 평균적으로 하락 조건의 bias가 높다는 관측과, 현재 CNN의 고정 kernel이 원인이라는 주장은 다르다.
- 수량 사분위는 거친 통제다. 특히>65 구간은 넓어 실제 수량·개체·시간 구성 차이가 남아 있다.
- signed bias는 양·음 오차가 상쇄되므로 RMSE·MAE와 함께 판단해야 한다.
- 세 seed는 같은 관측 대상을 사용한다. 별도 독립 모집단이나 통계적 유의성으로 해석하지 않는다.
- 과거 간격은 사용한 artifact에 없다. 미래 target gap을 대신 사용하지 않았다. 실제 수량이 이후 상승/하락했는지는 모델 입력·구간 판정에 사용하지 않았다.
- 이 분석은 기존 Test 결과를 본 이후의 탐색이며, 이번에는 Train·Validation만 읽었다.

## 남은 작업 순서

1. **관측된 단서와 보수적 기준 미충족을 검토한다 — 다음 작업.** 방향 차이는 반복되지만 Train 효과 크기가 약한 두 seed를 포함한 현재 결과를 기준으로, 추가 구조 구현의 근거가 충분한지 판단한다.
2. **후속 진단 또는 가설 검증 범위를 정한다 — 다음 작업.** 더 진행한다면 같은 과거 수량 구간 안의 개체 구성과 변화 크기를 맞춘 분석이 우선이며, 실제 예측을 다시 돌릴 필요는 없다. 이번 결과를 사전 성공 기준 통과로 바꾸지 않는다.
3. **새 구조 계약·구현·합성 검증 — 보류.** 근거 판단이 정리되기 전에는 배율·gate·추가 입력을 넣지 않는다. 공통 입력·손실·head·memory를 유지하고, 적응성 효과와 용량 효과를 구분하는 대조가 필요하다.
4. **GPU 학습 — 승인 필요.** 현재 실행하지 않았다. 향후 승인되는 학습은 5080/5090 서버당 최대3개 동시 실행, 같은 비교 묶음의 동일 host/Runtime 정책을 유지한다. 현재 서버 상태는 조회하지 않았다.
