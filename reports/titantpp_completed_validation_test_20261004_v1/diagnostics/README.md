# Intermittent Test Time NLL 관측 분해

고정된 폭4·폭16의 3개 seed에서 Test 평균 Time NLL은 15.377800에서 45.789041로 증가했다. 동일한 88,019개 target의 truth 필드 전체와 target/truth digest, loader, data SHA를 seed별로 다시 대조했다. 이 분석은 이미 선택된 checkpoint의 저장 예측만 사용했으며, 새 추론·학습·경계 탐색·checkpoint 재선택은 수행하지 않았다.

관측상 증가가 큰 수량 tail에 집중되지는 않는다. 고정 TRAIN 경계인 raw quantity >187의 tail은 243개(0.276%)이며, 증가분은 거의 모두 body에서 발생했다. >52주 관측은 없었다. 14–52주의 574개(0.652%)는 seed별 증가분의 8.24–29.90%를 차지했지만, 증가분의 가장 큰 구간은 seed42에서 2–4주, seed52·62에서 5–13주였다. 따라서 극단적인 긴 gap이나 수량 tail 하나만으로 증가를 설명할 근거는 없다.

Time NLL은 frozen contract의 `positive_integer_round_clamp_v1`, 단위 week, top code 없음에 따른 기록된 정수 간격의 lognormal PMF NLL이다. 표의 gap은 저장된 `recorded_gap`을 그대로 사용했으며, 모든 값이 1 이상의 정수임을 확인했다. 다른 모델의 결과와 이 폭4·폭16 관측 분해를 혼합하지 않는다.

## 해석 범위 및 증적

이 분해는 Test 손실 악화가 quantity body 안의 높은 NLL 관측에 집중되고, 중간 gap 구간과 드문 14–52주 구간 모두가 관여함을 보여준다. 예측 시간 분포의 위치·폭, 입력 이력, 모델 내부 상태는 저장 행에 없으므로 과신, 분산 축소, 외삽 실패 등을 원인으로 확정할 수 없다. 각 seed의 극단 손실과 평균 NLL 차이가 크다는 사실은 확인되지만, 이 기술적 분해만으로 구조 변경의 인과효과나 통계적 유의성을 주장하지 않는다.

- `intermittent_time_nll_groups.csv`: 폭·seed별 overall, gap, quantity body/tail, gap×quantity의 count/mean NLL/NLL 합/합 기여율.
- `intermittent_time_nll_extremes.csv`: p99, max, 상위 1% 기여와 구성.
- `intermittent_time_nll_paired_delta.csv`: 동일 target에서 폭16−폭4 증가의 구간별 분해.
- `intermittent_time_nll_verification.json`: source·registry·receipt·prediction 입력 SHA와 동일 target/truth 검증.
- `intermittent_test_time_nll.py`: 계산 코드.
