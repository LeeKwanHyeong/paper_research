# RAF Validation→Test 비교 해석

2026-10-15 20:30:15 KST 평가 완료. 신규 두 후보 × 3seed의 Validation6/Test6 실제 worker exit0, 두 단계 pipeline exit0 및 321개 파일 SHA를 확인했다. 기존 CNN3 Test는 고정된 증적을 재사용했다.

- 이력 적응 CNN은 Validation과 Test 모두 용량 대조군보다 세 seed 전부 전체 RMSE가 높다. 평균 MAE도 더 높고, seed42의 MAE만 용량 대조군보다 낮다. 따라서 RAF에서는 이력에 따른 가중치 조절이 같은 추가 용량보다 유리하다는 근거가 없다.
- 기존 CNN 대비 이력 적응 CNN의 Test 평균 RMSE는 0.047%, MAE는 0.643% 높다. 용량 대조군은 평균 RMSE가 0.139% 낮지만 MAE는 0.390% 높다. 일관된 전체 수량 성능 개선으로 해석할 수 없다.
- 큰수량(q>200) Test 대상은 39개다. 기존 CNN 대비 두 후보의 큰수량 RMSE·MAE 평균은 낮아졌지만, 큰수량 TimeNLL 평균은 높아졌다. 전체 TimeNLL 평균은 두 후보 모두 조금 낮다. 전체 오류와 부분 구간의 이득을 구분한다.
- 같은 5,226개 Test 대상의 관측 이력 평균 기준선은 RMSE 39.357906 / MAE 11.301169, 직전 수량 기준선은 RMSE 45.855031 / MAE 12.203597이다. 세 신경망 모두 관측 이력 평균보다 RMSE가 높고 MAE는 낮다. 단순 기준선 TimeNLL은 N/A다.
- 기존 CNN은 5080/cuDNN91900, 새 두 후보는 5090/cuDNN92000이다. 기존 CNN 대비 차이에 모델 구조만의 인과적 의미를 부여하지 않는다. 같은 5090에서 학습·평가한 Adaptive−Capacity가 주 대조다.
- 이 후보들은 기존 Test 접근 이후 설계됐다. 새 독립 평가, 통계적 유의성, 보편적 일반화 개선 또는 반전 원인 확정으로 해석하지 않는다. 선택 checkpoint를 Test로 재선택하지 않았다.
